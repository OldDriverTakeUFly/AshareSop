- cron:`30 18 * * 0`(每周日 18:30)
- 标题:`每周日18:30 本周市场群像(七角色仪表盘→长文+总结卡,20:30前推博主群)`

prompt 正文:

【定时任务·每周日18:30 本周市场群像】固定栏目:把本周(上周一~上周五,自然周)市场数据组装成多角色群像,产出小红书长文+群像总结卡,20:30 黄金档前推「红薯财经博主运营」群(发布永远人工)。工作目录 /home/leo/Projects/CodeAgentDashboard,解释器 .venv/bin/python,命令从仓库根目录跑。无人值守:异常记录后继续,事后报告。

■ 第0步 定义与边界
- 本栏目的层级定位:每日复盘卡=事实层,本栏目=解释层(资金行为);群像体=同一场景多角色并置,原型登记为系列第15号「群像体」。
- 差异化:查 docs/小红书卡片/未发布/ 与 docs/分析笔记/ 无近期同周群像文,有则作增量而非重复。

■ 第1步 数据仪表盘(无指纹不登场;证据齐才动笔)
按「角色卡」逐个取数(本周=周一至周五):
1. 抢跑者(主动机构):Tushare moneyflow 按 trade_date 拉本周逐日,主力净额(大单+超大单)重点行业/代表个股(.venv/bin/python heredoc,env 用 dotenv load_dotenv 显式根目录 .env 路径;find_dotenv 在 stdin 会炸禁用)。
2. 地板人(被动/ETF):web 搜索本周科创50ETF(588000)等核心 ETF 份额日变化(中国基金报网/集思录口径,带日期);拉不到全量就注明样本口径。
3. 情绪贩子(游资):本地 market_data.db limit_pool/dragon_tiger 查本周涨停池家数、连板最高度、龙虎榜营业部上榜数(sqlite3 只读)。
4. 成本锚(散户):moneyflow 小单净额本周累计;股东户数变化(web,季频,拉不到就标注)。
5. 外资(常驻角色,2026-09-16 定档):Tushare hk_hold 拉本周最新一日 vs 上周五的个股持仓变化(vol/ratio,前30大增减持)+ moneyflow_hsgt 余额日度差值;口径注明:2024-08 后北向净买入官方口径停发,用持仓变动近似。周五数据周五盘后即得,不存在时效风险。
6. 真股东(产业资本):本周 repurchase 进度行+stk_seasoned 终止/实施事件(Tushare,参照 studies/buyback_placement_event_study.py 的拉法)。
7. 统计学家(量化):仅推断,必须标注「推断」,不给数字。
8. 导演(政策):仅本周有明确政策事件时出场。
指数背景:index_daily 本周科创50/创业板指/上证/沪深300 周涨跌。

■ 第2步 长文(docs/小红书卡片/未发布/本周市场群像长文YYYYMMDD.md)
- 结构:场景钩子(本周最具画面感的一天)→ 角色 4-6 个逐个登场(每个≥1 个当日/当周数据指纹+一句思维方式:机构问预期差/被动问位置/游资问周期/散户问成本/外资问汇率与利差/产业资本问价值)→ 冲突与错位(同一事件各角色看到不同的东西;缺席也是角色)→ 收尾回合力与松动点(「下周看谁的筹码先松」)→ 互动钩子。
- 纪律:无指纹不登场;不道德化(每个角色在自身约束下都理性);数字全锚仪表盘输出(文件附来源锚点节);正文≤950字;敏感词避开 增持/减持/买入/卖出/下注/押注/目标价/止损/追高(全文自查);结尾信源行+免责;tags 单列且为消息最后一行。
- 文体登记:群像体,与既有 14 原型互异;标题带本周关键词+emoji。

■ 第3步 群像总结卡(cardgen,1-2 张,图卡+长文混合形态)
- init --topic 本周市场群像YYYYMMDD;facts.json 纪律:value 纯数字字符串,单位用验证器单位集(亿/万/元/%/家/只/板),source.ref=仪表盘查询指纹,quote=取数输出原文;as_of=周五,expires=下周三。
- 卡结构:一张「七角色本周动作表」(table 型:角色/本周动作/数据指纹)+可选一张「下周观察点」(summary 型);tag_top 禁日期;尾卡 foot 含「不构成投资建议」。
- validate ≤3轮 → build(新工程无需--bump)→ 逐张目检 scripts/content_publisher/vision.py(pass 全过才入池)→ cardgen enqueue + 原样执行 queue.py enqueue 命令,记池号。

■ 第4步 推群(20:30 前完成)
- stockhot.notification.feishu_bot.EnterpriseFeishuNotifier(FEISHU_APP_ID/SECRET, FEISHU_XHS_CHAT_ID),asyncio:逐张 send_image(总结卡)→ send_text:【本周市场群像 #池号·周日20:30黄金档,发布人工】标题+长文正文+tags(铁律:tags 最后一行,其后禁任何文字)。
- 推送失败单独重试一次,如实报告。

■ 第5步 留痕
- git add 长文+卡片工程 && commit「feat(cardgen): 本周市场群像YYYYMMDD——<一句话>(角色N个/池#A)」(不 push)。
- 最终消息:本周群像一句话主线/各角色指纹摘要/池号与推送结果/降级与缺数如实列出(某角色数据拉不到就不登场,写明)。
