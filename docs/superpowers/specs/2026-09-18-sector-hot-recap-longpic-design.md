# 板块热点复盘长图卡设计与剪刀差模式系统靠拢 — 设计 Spec

- 日期:2026-09-18
- 状态:已拍板(三项开放问题当日全部确认)
- 试验品:2026-09-18 光通信板块复活(数据已核实)
- 前置决策:2026-09-18 用户拍板「产业链研报→长图卡」(单长图四件套);本设计在其基础上回答「卡片系统能否完全向剪刀差图卡模式靠拢」

## 一、背景与决策

现状盘点:系统内长图形态已部分同源——日更天梯/龙虎榜长图(`scripts/daily_longpic.py`,炭黑+正红+金 A 风格)与产业链研报长图卡(电解家族/AI基建等手工工程)共享几乎相同的骨架(tag→h1→sub→hook→卡片小节→insight→foot),差异只在配色、组件丰富度与内容密度。

本设计拍板(用户 2026-09-18 逐项确认):

1. **靠拢范围 = 骨架统一+增量接入**:日更天梯/龙虎榜保持 A 风格不动(当天刚拍板,不重排);新增「板块热点复盘」形态采用剪刀差排版;三系列共享同一骨架与组件语义,只分系列配色。
2. **图卡形式 = 单张长图**(用户二次确认「我想要的还是以长图的形式」):与产业链研报长图卡同构——钩子首屏+研报密度单长图;多图轮播方案提出后被推翻,不采用。
3. 系统路径 = **方案A今晚 + 方案B验证后**:今晚按约定层(规范文档+手工组装+最小工具适配)出品;观感验证通过后另立 spec 提取共享组件库。否决方案C(全面模板化自动化)——剪刀差模式的价值在研报密度+手工叙事,机械模板会稀释。
4. 新系列配色 = **深蓝黑底 #0a0f1e + 琥珀金主强调 #f5b942 + 冰蓝次强调 #6db9ff**(「光」意象,用户认可先做出来看效果;与产业链系列、日更系列三足辨识)。
5. 内容口径 = 盘面热点复盘(事件向)+ 研报密度数据,不做基本面重研报(那是产业链研报的事)。

## 二、系统层:三系列一骨架(排版规范 v1)

### 2.1 骨架铁律(全系列通用)

```
tag徽章(系列名 · 日期) → h1钩子标题(≤3行,黄金三秒) → sub副题一句
  → [钩子短卡止于此] → 内容卡编号小节(一、二、…) → insight左边条金句 → foot(信源+免责)
```

- 首屏钩子铁律沿用:最大反差/核心背离/最响数字。
- 每张图(多图工程中的每张)独立成立:单图被点开、截图、流传时要能看懂,自带 tag 与 foot。

### 2.2 组件清单 v1 与颜色语义

组件(从剪刀差/AI基建/日更三系归纳):`stats三连大数字`、`点名册表格`、`vs对峙双栏`、`insight左边条`、`金字塔分层块`、`梯队分层块`、`note注脚`、`hook首屏卡`。

**颜色语义铁律(本次澄清,两类并存、用途分开)**:

- 行情涨跌数字(涨跌幅/收益列)一律 `up=红 / down=绿`(A股红涨绿跌,与日更卡 2026-09-18 修正口径一致);
- 定性好坏(事实正负,如「全行业亏损」「净利+233%」)用 `pos=青绿 / neg=粉红`(剪刀差系原型语义);
- 同一表格内两类列并存时按列用途取色,不得混用。

## 三、新形态定义:板块热点复盘长图卡

- 定位:事件驱动的盘面热点复盘(某板块某日异动),钩子首屏+证据+结构+风险单长图叙事。
- 与相邻形态的边界:日更数据卡=全市场机械数据(无人值守);产业链长图卡=深度基本面研究;板块热点复盘=单事件横截面(手工叙事、选题材人工/agent 判断)。
- 首个工程目录:`docs/小红书卡片/未发布/板块热点复盘/2026-09-18_光通信复活/`(用户已认可命名)

### 工程结构(标准四件套,与产业链长图卡同构)

```
板块热点复盘/2026-09-18_光通信复活/
  长图.html / 长图.png   ← 750px 单长图,钩子首屏,超 9000px 沿用拆上下规则
  文案.md                ← 钩子笔记正文(结构同长文图卡文案:来源锚点/终版发稿文案/tags末行/图片清单)
  facts.json             ← 全图全数字溯源
```

- 不入 cardgen 台账、不 enqueue(与长文图卡同待遇);备料推送走 push_longpics 通道;发布永远人工。

### 工具链最小适配(方案A允许范围)

`未发布/render_longpics.py` 与 `未发布/check_overflow.py`:PROJECTS 列表各加一行新工程路径即可(两脚本按 `BASE/工程/长图.html` 寻址,天然兼容);`push_longpics.py` 出品后按需同步。不改 daily 管线、不改 cardgen。

## 四、数据与 facts 纪律

- 图上任何数字必须登记 facts.json:`id/value/display/as_of/source{kind,ref}/expires`,口径写进 ref。
- 行情:`market_data.db:daily_price:{ts_code}:20260918:pct_chg|close`;回撤类计算=`close / max(close, 20260601-20260918) - 1` 口径明示。
- 板块资金:`stockhot.db:daily_data:fund_flow_sector@2026-09-18:{板块}:main_net|change_pct`。
- 涨停池:`stockhot.db:daily_data:limit_up_pool@2026-09-18:{code}:first_seal_time` 等。
- 温度:`market_data.db:thermometer_sector@{日期}:通信设备:temperature|delta_temp5`(出品时若 19:35 后 9-18 口径已出则用最新并标注,否则用 9-17 并明示日期)。
- 催化(图4 用):出品时 web 搜索当晚催化,来源锚新闻链接写进 facts(ref=媒体+日期)。
- 时效闸:全部数字 `expires ≤ 2026-09-23`(5 天窗口),发稿文案标注「数据截至 9-18」。

## 五、合规与发布

- 敏感词:出品时对全部 `图*.html` + `文案.md` 跑 cardgen 敏感词全表(`cardgen/compliance.py` 词表)零命中,命中改措辞,不用豁免。
- 表述:复盘事实口径,不荐股、不指代买卖;结论以事实/区间表述;每图 foot 带「不构成投资建议」。
- 温度计反向语义铁律:低温回暖只能解读为「关注度回流」,严禁写成买入信号(2026-09-17 部署纪律)。
- 文案 tags 必须最后一行(群推送铁律沿用)。
- 发布永远人工。

## 六、试验品:光通信复活(单长图)
