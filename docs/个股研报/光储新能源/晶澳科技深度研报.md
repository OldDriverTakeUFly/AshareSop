## 第一章：公司概览与发展历程

> **强制要求**：本章呈现晶澳科技的"靳保芳 + 河北宁晋"基因——从县电力局局长抵押房产 50 万元创办半导体厂，到与日本松宫合资打造全球最大单晶硅基地，再到"纳斯达克→私有化→借壳回 A"的完整资本轮回，这是中国光伏"体制内创业者"的标本。

### 1.1 创始人与管理层——从县电力局局长到"中国硅王"（web 搜索 D-web1/D-web2/D-web5）

晶澳是三家组件巨头中唯一由**体制内干部下海**创立的公司：创始人靳保芳以宁晋县电力局党委书记/局长之身，1996 年抵押房产筹集 50 万元创办半导体厂，三十年间把它做成全球组件前三——媒体称其完成了"从县电力局局长到中国硅王"的跨越（D-web2 国际新能源网）。

> **核心洞察（治理对比）：** 晶澳的基因是**"体制内稳健 + 产学研起点 + 老练资本运作"**——区别于晶科李仙德的"兄弟家族技术激进"（《晶科能源深度研报》1.1）与天合高纪凡的"理科硕士三次跨行创业"（《天合光能深度研报》1.1）。靳保芳 74 岁仍执掌帅印，三巨头中唯一未完成二代接班——**接班安排是晶澳治理层面的最大悬念**。稳健的另一面是弹性弱：2023 年晶澳归母 71.92 亿 vs 晶科 74.40 亿几乎并肩，但 2025 年亏损期晶澳亏得最少（-46.08 vs -68.82/-70.31 亿）——**稳健基因在下行期的价值正在兑现。**

## 第二章：业务范围与产品矩阵——稳健一体化 + 分布式渠道 + TOPCon/BC 双线

### 2.1 经营范围（法定）

硅片、电池片、组件的研发生产销售，光伏电站开发运营，储能系统及户用光储解决方案。核心是**"硅片→电池→组件"高一体化率制造 + 分布式渠道深耕 + 光储延伸**。

### 2.2 核心产品矩阵——四大业务板块

### 2.3 一体化深度拆解——"全链但克制"的结构差异（本章灵魂之一）

三家组件巨头都做一体化，但结构不同——晶澳的独特性在于**纵向比例最高、横向扩张最克制**：

| 一体化维度 | 晶澳 | 晶科 | 天合 |
|-----------|------|------|------|
| 硅片自给率（产能/组件产能） | **≈80%**（D-web4） | ≈92%（120/130GW） | 低（外购为主） |
| 电池自给率 | **≈70%+**（D-web4） | ≈85%（110/130GW） | 中（部分外购） |
| 上游硅料布局 | 无 | 无 | 无 |
| 2020-2022 硅料暴涨期策略 | 克制扩产、未激进锁量 | 激进扩产一体化 | 支架/储能多元化分兵 |
| 结果（2025 亏损） | **-46.08 亿（亏最少）** | -68.82 亿 | -70.31 亿 |

> **核心洞察（一体化的盈亏对称性）：** 高一体化在景气期是利润放大器（2023 年晶澳 71.92 亿 vs 天合 59.98 亿），在出清期是亏损放大器（全链价格战下每个环节都亏）——但晶澳 2024-2025 亏得最少，说明其"克制"体现在**资本开支节奏**而非一体化深度：同样的全链结构，晶澳的产能投放更晚、单位投资更低、包袱更小。**一体化率最高+扩产最克制的组合，本质是"把一体化做成了纪律而非豪赌"。** 2024Q4 单季 -42 亿减值后，资产负债表的主要风险敞口已一次性暴露（D-web4 财联社"资产减值成业绩杀器"），2025-2026 的续亏更多是经营性而非减值性——这是"减值出清接近尾声"的信号。

> **核心洞察（技术路线的风险对冲结构）：** 晶澳的双线布局是三巨头中"工程上最不性感、投资上最稳健"的：TOPCon 主线确保主流市场不掉队（量产 27% 效率与晶科 26.7%+ 量产同档），BC 支线只在户用等差异化场景试水——**如果 TOPCon 赢，晶澳不掉队；如果 BC 赢，晶澳有门票**。对比晶科（TOPCon 单线，赢了通吃/输了重造 110GW 电池产能）与隆基（ALL in BC，高风险高弹性），晶澳支付了少量冗余成本换取路线风险的免疫。**周期底部，技术路线的"不押错"本身就是最大的 α。**

### 2.5 分布式与户用渠道——"晶澳兴家"的渠道护城河（本章灵魂之三）

> **核心洞察（为什么分布式渠道在出清期值钱）：** 分布式/户用市场的定价逻辑与集中式完全不同——集中式拼价格（0.71 元/W 的成本战，D-光伏），分布式拼渠道与服务（分布式组件 0.745 元/W 溢价 0.035 元/W，InfoLink 2026.7.8）。晶澳户用渠道（兴家品牌+经销商网络）意味着：① 组件价格战中始终有一块溢价市场；② 中国农村市场的渠道沉底是护城河（经销商体系数年建设）；③ 户用光储出海把渠道复制到欧洲/非洲/南美。**对比：晶科强在海外集中式大客户（80% 海外出货），晶澳强在分布式毛细血管——出清期分布式溢价的贡献虽小（0.035 元/W×35GW 分布式出货 ≈ 1.2 亿/年，估算），但复苏期户用光储的渠道变现弹性大。**
