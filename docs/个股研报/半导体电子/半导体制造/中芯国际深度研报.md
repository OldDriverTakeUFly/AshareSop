## 第一章:公司概览与股东背景

### 1.1 创始人与管理层

**创始人——张汝京("中国芯片代工之父")**

中芯国际由张汝京博士于 2000 年 4 月创立于上海。张汝京出身德州仪器,曾在台湾联华电子、世大集成电路任职,拥有 30 余年半导体建厂与运营经验。2000 年他率数百名台籍工程师赴上海张江创办中芯,四年内建成三座 8 英寸厂和一座 12 英寸厂,创造了中国半导体史上最快的建厂纪录(公司官网/公开报道)。2009 年因台积电诉讼案和解离任,但其奠定的"大陆第一代工平台"底座延续至今。

**现任管理层——"产业老将 + 双技术 CEO"组合**

| 职务 | 姓名 | 背景 | 履历要点 |
|------|------|------|---------|
| 董事长/执行董事 | **刘训峰**(1965 生) | 教授级高工,华东理工化工学士/硕士、西安交大管理博士、中欧 MBA | 原上海华谊集团董事长(化工央企),2023-05 任中芯副董事长、2023-07 接替高永岗任董事长(大基金推荐人选);第十四届全国政协委员(新浪财经高管资料/公司披露) |
| 联合 CEO | **赵海军**(1963 生) | 清华无线电系学士(1988)、清华微电子博士(1994,李志坚院士)、芝加哥大学 MBA | 30+ 年半导体运营经验;2010 加入中芯,2013 任 COO,2017 接邱慈云任 CEO,2017-10 起与梁孟松共任联合 CEO(新浪财经/公司年报) |

> **核心洞察**:中芯的管理层结构是"**国资董事长管资本与战略 + 双技术 CEO 管研发与运营**"。刘训峰的化工央企背景+大基金体系人脉,匹配中芯"国家级战略资产"的融资与扩产需求;赵海军(运营)与梁孟松(工艺)的双 CEO 架构自 2017 年延续至今,是中芯在实体清单约束下仍能推进先进制程的组织保障。风险点是该架构对两位 1960 年代出生 CEO 的依赖度极高,接班安排未见公开披露。

## 第二章:业务范围与产品矩阵

### 2.1 经营范围(法定)

集成电路晶圆代工(Foundry):8 英寸与 12 英寸晶圆的制造服务,覆盖 0.35μm 至 14nm 及更先进节点的逻辑工艺,以及 NAND Flash 等非易失性存储、电源管理、射频、CIS、BCD 等特色工艺平台。

### 2.2 核心产品矩阵——"先进制程 + 成熟制程 + 特色工艺"三线

| 业务线 | 主力节点/平台 | 典型应用 | 行业地位 |
|--------|--------------|---------|---------|
| **先进逻辑(FinFET)** | 14nm、N+1/N+2(类 7/8nm,公司未官方命名)、N+2 衍生 | 智能手机 SoC、AI 推理、矿机、国产 GPU | 大陆唯一量产 FinFET 代工(媒体分析:华为麒麟系列由 N+2 代工) |
| **成熟逻辑** | 28/40/55/65/90nm…0.35μm | SoC、MCU、物联网、消费电子 | 全球成熟制程产能龙头之一,大陆绝对第一 |
| **特色工艺** | 电源管理(BCD)、射频(RF SOI/CMOS)、CIS、存储接口、eNVM | PMIC、射频前端、摄像头、MCU | 大陆平台覆盖最全;与华虹/格芯直接竞争 |

**2025 收入结构特征**(公司年报/业绩会口径):
- 按尺寸:12 英寸收入占比 74.7%(2026Q2,券商测算经财联社转引),8 英寸以特色工艺为主;月产能(折 8 英寸)109.65 万片(2026Q2,Q1 为 107.83 万片)
- 按地区:中国区收入占比 85.6%(2025 全年,公司年报),国产替代深化
- 按应用:智能手机/消费电子各约 1/4 量级;**2026Q2 AI 配套芯片(电源/互联/接口等)收入环比 +40%**(公司业绩会,EET China),AI 正在成为新增长极
- 量价结构:2026Q2 销售晶圆 286.95 万片(环比 +14.4%、同比 +20.1%),**晶圆 ASP 由 Q1 的 937.63 美元升至 990.87 美元(环比 +5.7%)**——量价齐升(财联社业绩会直击)

### 2.3 技术代际演进与技术发展方向(强制!)

**当前技术代际**:先进制程量产主轴为 14nm 与 N+1/N+2 系(7-8nm 级,DUV 多重曝光);受实体清单限制,7nm 以下(EUV 依赖)暂无公开量产路径。

```
技术演进路线(DUV 可达边界内):
0.35μm → 0.13μm(CPU 时代) → 90/65nm(HKMG) → 40/28nm(HKMG+,
                                     2013 量产) → 14nm FinFET(2019)
→ N+1/N+2 类 7/8nm(2022-2023 媒体证实,DUV 多重曝光)
→ [EUV 断供边界] → 更先进节点的国产设备/EUV 替代路径(未验证)
```

**关键观察**:
1. **DUV 多重曝光的代价**:N+2 的良率与成本显著劣于台积电同期 EUV 工艺,但管制环境下"有与没有"比"贵与便宜"更重要——这是战略溢价的产业基础
2. **成熟制程的规模壁垒**:28nm 以上产能全球占比持续提升(大陆新增产能主要载体),规模→折旧摊薄→毛利率改善,2026Q2 毛利率 25.3%→Q3 指引 26-28% 正是该逻辑兑现
3. **未来技术布局**:公司研发投入 2025 年 55.19 亿元(fina_indicator,占营收 8.2%),方向包括更先进 DUV 节点、国产设备验证、先进封装配套(公开披露口径)

> **核心洞察**:中芯的护城河不是"技术领先"(台积电领先两代以上),而是"**管制环境下的大陆唯一性**"——先进制程的国产载体地位无替代者,成熟制程的规模与平台广度大陆第一。这决定了它的估值范式:不能按"全球代工同业 PB 2-4x"机械锚定,但也不能无限透支战略溢价——A/H 88% 溢价就是这个矛盾的定价表达。

### 2.4 海外/新兴业务

- 海外收入占比约 2 成以下(公司年报趋势);美国管制下北美客户收入结构性下降
- H 股平台(0981.HK)是国际资本参与中芯的主要通道;A/H 溢价长期存在(当前约 +88%)

### 4.2 G 与 ΔG 的人工核算(以 Q2 公告修正)

| 口径 | G(营收同比) | ΔG(增速变化) |
|------|-------------|---------------|
| 2026Q1(A 股) | +8.1% | vs 2025Q4 +12.3% → **-4.2pp** |
| 2026Q2(公司公告,美元) | **+36.1%** | vs Q1(美元口径约 +2-3%,华尔街见闻环比 +0.7% 推算) → **+33pp 级别跳升** |
| 2026Q2(人民币折算,自算) | 约 +26% | vs Q1 +8.1% → **+18pp** |

**结论**:无论美元还是人民币口径,**ΔG 在 2026Q2 均大幅转正**——营收增速从个位数跳升至 26-36%。叠加毛利率 25.3%→26-28% 指引,这是典型的"**量价齐升式二次点火**"。

### 4.3 山峰理论定位

```
              营收增速 G — 山峰
                /\
               /  \
    左山坡    /    \   右山坡
   (ΔG>0)   /      \  (ΔG<0)
            ↑
      2025Q1-Q1'26:山坡下滑(G 29%→8%)
            ↑
      2026Q2 起:重新上山(ΔG +18~33pp,G 回到 26-36%)
      → 位置:第二座山峰的"左山坡中段"
```

**定位**:第一轮景气峰(2025Q1,G≈29%)经过四个季度减速后,**2026Q2 开启第二座山峰的爬坡**。山峰理论下"二次上山"的持续性取决于:涨价周期长度(Q3 指引 26-28% 毛利率仍是上行)、AI 需求外溢深度、2027 年新产能释放节奏。

### 4.4 30% 阈值检验

- 美元口径 G=+36.1% **超过 30% 阈值** ✓(人民币口径 +26% 略低于)
- 判定:**进入高景气加速区**(美元口径)

### 4.5 二次点火筛选

| 条件 | 中芯状态 |
|------|---------|
| G 高(≥30%) | ✓ 36.1%(美元口径,Q2 公告) |
| ΔG 正 | ✓ +18~+33pp(Q2 vs Q1) |
| 经营现金流正 | ✓ 2026Q1 +51.32 亿(Tushare) |
| 毛利率上行 | ✓ 21.48% → 25.3% → 指引 26-28% |

**结论**:**四条件全过——二次点火成立**(2026Q2 数据口径)。这是本报告与仅看 A 股 Q1 数据的"下降拐点"结论的根本分歧,以后者(最新公告)为准。

## 第六章:强势点与弱势点

### 6.1 强势点(Strengths)

1. **战略唯一性**:大陆唯一先进制程量产载体,实体清单反成"订单护城河"(国产替代强制迁移)
2. **规模与平台**:月产能(折 8 英寸)超 100 万片(2025),大陆第一;成熟制程+特色工艺平台最全
3. **盈利弹性兑现**:Q2 毛利率 25.3%→指引 26-28%,涨价+稼动率双杠杆,净利 +217.5%
4. **A+H 资本平台+国资同盟**:大基金+四地国资合资,扩张资金链最厚
5. **现金流造血**:经营 CF 常年 200 亿+量级,远超账面利润

### 6.2 弱势点(Weaknesses)

1. **技术代差**:先进制程落后台积电两代以上,DUV 多重曝光的良率/成本劣势无法靠规模弥补
2. **毛利率天花板**:25-28% vs 台积电 67.7%、联电 32.5%——管制导致的设备折旧年限短+良率损耗结构性压制
3. **估值高位**:A 股 PB 92.4% 分位、A/H 溢价 88%,安全边际薄
4. **自由现金流深度为负**:约 84 亿美元年 capex(2025),依赖外部资本持续输血(2025 年度不派息,因资本开支预计超净资产 20%,公司披露)
5. **散户化倾向**:股东户数 2025Q3 暴增 33%,筹码结构松动
