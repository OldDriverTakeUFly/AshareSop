## 第一章:公司概览与股东背景

### 1.1 创始人与管理层(2026-08 现状:v2.0 更新)

**华虹集团背景——国资央企基因**

华虹宏力是**上海华虹集团**旗下核心企业。华虹集团是中国半导体"国家队",1990 年代承担国家"909 工程"(中国第一条 8 英寸晶圆线),是中国集成电路产业的奠基者。实际控制路径:上海市国资委→华虹集团→华虹半导体(A+H 上市主体)。

**管理层三年三换帅(v2.0 重大更新)**:

| 2025-01 起 | 唐均君 | **白鹏**(新任) | 白鹏(前英特尔全球副总裁,30+ 年 IC 制造经验)2025-01-01 任执行董事兼总裁 |
| 2025-11 起 | **白鹏(兼任)** | 白鹏 | 唐均君 2025-10-31 辞任全部职务(2026-05 转任和辉光电董事长);白鹏**集董事会主席+总裁于一身**(公司公告,财联社/国际金融报) |

### 2.4 技术代际演进与技术发展方向(强制!)

**当前技术代际**:特色工艺成熟节点——8 英寸(0.5-1.0μm 功率)+12 英寸(55-90nm 平台)+Fab9(65/55-40nm 车规)+**华力微(28-14nm 逻辑)**。

```
特色工艺演进:功率 DMOS → SGT → 超级结 → IGBT → SiC/GaN(下一代)
嵌入式存储:90nm → 55nm → 更先进
逻辑(华力微):55/40nm → 28nm → 22nm → 14nm(并表后新增能力)
制造平台:上海 8 寸 → 无锡 12 寸(Fab7→Fab9)→ 华力微 12 寸
```

**关键技术优势与方向**:

| 维度 | 华虹地位 | 备注 |
|------|---------|------|
| 8+12 英寸功率代工 | **全球首家** | 同时具备两种尺寸 |
| IGBT/SiC | 国内领先/布局中 | 新能源刚需 |
| eFlash | 全球前三 | MCU 核心 |
| 28-14nm 逻辑 | 并表华力微获得 | 与中芯形成"大陆逻辑代工双雄" |

> **核心洞察**:华力微并表是华虹技术版图的**代际跳跃**——从"不做先进逻辑追赶"的特色工艺厂,一步跨入 28-14nm 逻辑代工(大陆仅次于中芯的先进逻辑产能)。这改变了公司的估值范式:从"特色工艺周期股"变为"特色工艺+逻辑工艺双平台",对标组合从格芯/联电向"小中芯"迁移。但 323.59% 的收购增值率意味着商誉与整合风险同样新增(见 §9)。
