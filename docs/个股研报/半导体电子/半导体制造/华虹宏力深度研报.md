## 第一章:公司概览与股东背景

### 1.1 创始人与管理层

**华虹集团背景——国资央企基因**

华虹宏力是**上海华虹集团**旗下核心企业,具有深厚的国资央企背景。华虹集团是中国半导体产业的"国家队",1990 年代承担了国家"909 工程"(建设中国第一条 8 英寸晶圆生产线),是中国集成电路产业的奠基者之一。

**管理层特点**:

- 华虹宏力的管理层具有**国资 + 半导体产业**双重背景,管理层由上海市国资委和华虹集团任命。
- 公司采用**职业经理人 + 国资监管**的治理结构,稳定性高,但激励机制相对市场化企业较弱。
- 当前具体董事长/总经理姓名需以最新年报披露为准(本报告标注"待 2026 年报核实")。

**管理层特点表格**

| 维度 | 描述 |
|------|------|
| 实控人 | 上海华虹集团(国资央企),上海市国资委 |
| 公司性质 | 国资控股,A+H 双重上市(688347.SH / 01347.HK) |
| 管理风格 | 国资稳健型 + 产业深耕,长期主义 |
| 战略定位 | 全球特色工艺代工龙头(功率器件 + 嵌入式存储) |
| 历史背景 | 承接国家"909 工程",中国半导体产业奠基者 |
| 员工规模 | 万人级(大型晶圆厂) |
| 总部 | 上海 |

> **核心洞察**:华虹的国资央企背景是其核心特征。与中芯国际(混合所有制)不同,华虹是纯国资控股,这种结构带来:(1) 长期资本耐心,能穿越半导体周期;(2) 国家战略支持,国产替代优先级高;(3) 但激励机制相对僵化,人才吸引力弱于民企。华虹的竞争力在于**特色工艺的长期积累**——功率器件、嵌入式存储等工艺需要 10-20 年沉淀,民企难以快速复制。

### 2.4 技术代际演进与技术发展方向(强制!)

**当前技术代际位置**:华虹处于特色工艺的**成熟节点**——功率器件以 8 英寸(0.5-1.0μm)和 12 英寸(55-90nm)为主,嵌入式存储以 55nm 12 英寸平台为主。

**特色工艺代际演进**(不同于逻辑芯片的制程追赶):

```
8 英寸(成熟)→ 12 英寸(55nm 平台)→ 12 英寸(更先进节点)
功率器件: DMOS → SGT → 超级结 → IGBT(SiC/GaN 下一代)
嵌入式存储: 90nm → 55nm → 更先进
```

**关键技术优势**:

| 维度 | 华虹地位 | 备注 |
|------|---------|------|
| 8+12 英寸功率代工 | **全球首家** | 同时具备两种尺寸 |
| IGBT 代工 | 国内领先 | 新能源汽车需求 |
| eFlash | 全球前三 | MCU 核心 IP |
| SiC/GaN(第三代半导体) | 布局中 | 下一代功率器件 |

**未来技术布局**:

- **第三代半导体(SiC/GaN)**:功率器件下一代方向,新能源汽车/快充刚需。
- **12 英寸产能扩张**:无锡 12 英寸厂扩产,提升规模。
- **汽车电子工艺**:智能驾驶芯片工艺平台。

> **核心洞察**:华虹的技术策略是**不做先进制程追赶**(那是中芯国际/台积电的逻辑芯片游戏),而是深耕**特色工艺的差异化壁垒**——功率器件、嵌入式存储等工艺需要长期 know-how 积累,客户粘性强,毛利率虽低于先进制程但波动小。SiC/GaN 是下一代增长点,华虹已开始布局。

### 2.5 海外/新兴业务

华虹以国内客户为主(国产替代逻辑),海外业务占比有限。港股 01347.HK 上市提供了一定的国际化平台。

### 3.2 周期底部与修复的成因诊断

华虹 2024-2025 的亏损由以下因素驱动:

1. **半导体下行周期**:2023-2024 年全球半导体去库存,功率器件/嵌入式存储需求疲软。
2. **产能利用率不足**:下行周期产能利用率下降,固定成本摊薄不足,毛利率压缩。
3. **价格压力**:特色工艺价格竞争,毛利率从 35.9% 跌至 17.4%。

**2026 盈利修复驱动**:

1. **特色工艺全线提价**:2026 年特色工艺全线涨价(IICIE 2026)。
2. **产能利用率满载**:产能利用率攀升至 95.8%-109.5% 创 2023 以来新高(小牛行研 2026)。
3. **产能扩张**:产能稳步攀升至 46.8 万片/月(2025)。

### 9.1 主要风险(≥4 条,编号)

1. **估值回调风险**:当前 PB 95.8% 分位、PS 95.8% 分位、PE-Band Q1(最危险象限),**估值处历史最高位**。若半导体板块降温或盈利修复不及预期,可能剧烈杀估值。

3. **特色工艺涨价持续性风险**:2026 全线提价是景气上行的结果,但一旦产能释放(行业扩产)或需求回落,价格可能快速回落,毛利率承压。

6. **资本开支压力**:2025 资本开支 -129.31 亿元,自由现金流 -78.66 亿,持续扩张依赖外部融资。

7. **A+H 溢价风险**:A 股 688347 相对港股 01347.HK 可能有溢价,若溢价收敛,A 股承压。
