### 2.4 技术代际演进与技术发展方向(强制!)

**演进主线——"制程受限 → 系统级代偿"**:

```
第一代(2020-2022): BR100/104,台积电 7nm 巅峰算力路线 → 被断供终结
第二代(2023-2025): BR106/110/166,Chiplet+CoWoS 封装代偿制程,D2D 896GB/s
第三代(2026+):     BR20X(FP8/FP4)+ NPO 光互连超节点(1024 卡 Scale-up)+ BLink 2.0
                    ——从"追赶单芯片算力"转向"集群有效算力"竞争
```

**关键判断**:在先进制程被锁死的约束下,壁仞选择的是**把竞争维度从"单卡峰值算力"切换到"超节点有效算力/互连密度"**——光互连(光跃/NPO)是其对 NVLink/NVSwitch 体系的差异化回应。这条路的天花板取决于国产先进封装(CoWoS 类)产能与光模块/光交换器件的成熟度。

**未来布局**:BR20X 商业交付(2026)、千卡级 LightSphere X、BIRENSUPA 生态深化(Day 0 适配扩容)、A 股辅导推进(回归 A 股的潜在第二上市)。

> **核心洞察**:壁仞的护城河叙事 = "**Chiplet 封装代偿 + 光互连超节点 + CUDA 兼容软件栈**"。它与沐曦(全国产制程闭环)、摩尔线程(全功能 GPU+MUSA)构成三种"绕开英伟达"的路线实验;而 BR100 那颗"未能量产的巅峰芯片"既是它的技术名片,也是其路线风险的历史注脚——**再强的单芯片设计,没有可控供应链都无法变现**。

### 9.1 主要风险(编号)

7. **A 股辅导不确定性**:辅导已近 2 年仍未申报,回归预期可能持续落空。
