## 第一章：公司概览与股东背景

### 1.1 创始人与管理层

工业富联没有传统意义上的"创始人"——它是**郭台铭创立的鸿海精密（富士康）体系于 2018 年分拆出来的 A 股上市载体**。

- **实际控制背景**：郭台铭为鸿海集团最大个人股东（持股约 13.42%，第一财经），鸿海精密通过**中坚公司（Foxconn Far East）** 间接控制工业富联，上市至今控股地位稳定。郭台铭 2015 年股东大会即提出"3-5 年内分拆子公司上市"的规划，工业富联是其中最大的一步棋（第一财经）。
- **管理风格与战略视野**：郭台铭时代的富士康以"垂直整合 + 极致成本控制 + 大客户绑定"著称；工业富联管理层延续这一基因，但在 2023 年后由**郑弘孟（董事长）** 主导向"AI 算力平台服务商"转型——从卖机柜到参与客户下一代平台（Vera Rubin）的联合研发设计（公司 2026 半年报），说明其角色正从纯代工向 JDM（联合设计制造）上移。
- **治理特征**：台资控股 + A 股上市的双轨结构，管理层技术执行能力强（全球最大规模服务器制造体系），但中小股东对关联交易定价、利润分配的议价权有限。

| 维度 | 内容 |
|------|------|
| 控制链 | 郭台铭 → 鸿海精密 → 中坚公司 → 工业富联（约 13.42% 为郭对鸿海持股，招股书/一财） |
| 董事长 | 郑弘孟（2023 年后主导 AI 转型，公司公告） |
| 员工规模 | 全球数十万级制造体系（鸿海体系口径，估算） |
| 总部/上市 | 深圳/上海主板 601138，2018-06-08 上市 |

> **核心洞察**：理解工业富联的第一把钥匙是"它是鸿海体系内**盈利质量最好的资产包**"——2018 年上市当年其营收约为鸿海集团的 39%、净利润约为鸿海的 65%（证券时报）。鸿海把通信网络设备、云服务设备、精密工具、工业机器人四块注入，从"总资产和净利润均为 0 的壳"起步（妙投）。这意味着工业富联的竞争壁垒本质上是**鸿海全球制造网络的期权**，而非独立公司的独立能力。

### 1.2 发展历程

> **核心洞察**：公司发展史是"一个 0 到 0.39 个鸿海、再从代工壳进化为 AI 机柜霸主"的两段式。2018 年上市时的"工业互联网"叙事从未真正兑现（工业互联网软件业务至今占比微小），真正兑现的是 2023 年之后的 AI 硬件周期——**叙事换了三次，能力圈（大规模精密制造）只扩了一次**。这是评估其未来叙事（HVDC、Rubin）可信度时最重要的历史锚。

### 1.3 公司定位与业务布局

- **一句话定位**：全球出货规模最大的 AI 服务器整机柜（GB200/GB300 NVL72）设计与制造平台，英伟达在整机柜环节的第一供应商。
- **全球布局**：依托鸿海全球制造网络——中国大陆（深圳、郑州、太原等）为核心制造基地，海外产能覆盖印度、越南、墨西哥、美国（威斯康星/得州）等地，形成规避关税与贴近北美云厂商的双重布局（鸿海体系公开信息，估算级）。北美 AI 机柜就近交付能力是其相对台系同行的关键优势之一。
- **客户结构**：英伟达（整机柜方案）、北美头部云服务商（CSP，含 GPU 与 ASIC 两条产品线）、国内互联网大厂。2026H1 云服务商板块收入占比持续提升（公司半年报）。

### 1.4 股东结构特征

总市值 12,708 亿元（tushare daily_basic 20260828），A 股主板上市，无 H 股。控股股东为鸿海系（外资控股的民企背景），无国资成分。流通盘大（超大盘蓝筹，沪深 300/上证 50 权重股）。**股权结构稳定，但二级市场筹码高度流动化**——详见第三章股东户数小节。

### 2.1 经营范围（法定）

云计算服务器与存储设备、通信网络设备、精密结构件、工业机器人及精密工具的研发与制造（招股书法定口径）。

### 2.4 技术代际演进与技术发展方向（强制章节）

- **当前技术代际**：服务器代工的代际由**客户平台**定义。当前主流 = 英伟达 GB200/GB300 NVL72（Blackwell），2026 年 GB300 整柜方案已成出货主力，需求延续至 2027 上半年（TrendForce 2026-08）。工业富联在 GB200 世代份额约 69%（研报引述），GB300 世代预计 45-50%（研报引述）——份额下移但盘子扩大。
- **整机柜价值量**：GB200 NVL72 单柜售价约 330-350 万美元（量产版约 300 万美元，鸿海口径；AI 服务器专家交流会 2025-07），GB300 较 GB200 系统价值量高约 20%（财联社测算）。NVL72 内部价值量拆解：PCB 约 2.5-3.4 万美元/柜（财联社），液冷大冷板单块约 650 美元、奇鋐份额超 55%（腾讯新闻拆解）——**整机柜中最大的价值量在 GPU 模组本身，代工厂获取的是组装、机柜级设计、液冷集成与测试环节的价值**，这决定了毛利率天花板（见第三章）。
- **演进路径**：GB200/GB300（当前）→ **Vera Rubin VR200（2027）** → Rubin Ultra + Kyber 机架（2027-2028）。TrendForce 预估 2027 年 NVL72 类机柜产值突破 7,100 亿美元、年增 214%。
- **未来技术布局（两条新曲线）**：
  1. **800V HVDC 供电架构**：英伟达宣布 2027 年起向 800V 高压直流过渡以支持 1MW 级机架（NVIDIA 开发者博客），且**正联手富士康/工业富联推动 HVDC 落地**（财联社 2168376）。若工业富联从"机柜组装"延伸到"供电架构与电源架"，单位价值量将系统性上移。
  2. **Vera Rubin 平台联合研发**：半年报明确披露"已在英伟达下一代 Vera Rubin 平台提前布局，与大客户联合研发设计"（公司 2026 半报）——JDM 属性增强。

> **核心洞察**：工业富联的技术护城河不在芯片（零自研 AI 芯片），而在**"百万 GPU 级别机柜的工程化交付能力"**——液冷集成、信号完整性、良率爬坡、全球多点并行交付。800V HVDC 是其价值量上移最现实的路径：从"每一柜收一次组装费"变成"每一柜收一次组装费+供电架构费"。但需诚实标注：HVDC 商业模式（分成还是纯代工）尚未披露，属期权而非既得。

### 2.5 海外/新兴业务

ASIC AI 服务器（CSP 自研芯片路线）是增长最快的第二曲线：2026H1 ASIC 机柜出货 +3 倍、ASIC CPU 服务器 +2.5 倍（公司半年报）。这条线与 GPU 线形成"英伟达 + 云厂商自研"的双轮对冲。

### 3.2 拐点成因诊断：为什么利润增速（+95.7%）远超营收增速（+54.6%）？

1. **产品结构上移**：高单价的 GPU/ASIC AI 机柜占比快速提升，摊薄固定成本。GB300 整柜价值量较 GB200 高约 20%（财联社），机型换代本身即贡献单价上行。
2. **毛利率结构性改善但绝对值仍低**：2026H1 毛利率 7.15%（tushare fina_indicator 20260630），对比台系同业广达 4.8%（2026Q1，经济日报）、浪潮服务器业务约 4.52%（2025 年报口径）——**工业富联已是主要整机厂中毛利率最高的**，但"代工宿命"未变。
3. **规模效应 + 自动化**："客户覆盖范围持续拓展深化，产线自动化交付水平持续升级，整体出货效率稳步增强"（公司官网新闻稿 2026-08）。
4. **研发投入绝对额抬升**：2026H1 研发费用 49.98 亿元（tushare income 20260630），研发强度约 0.9%——绝对额是 A 股硬件公司前列，但强度仍为代工型。

### 3.3 资产负债表与现金流质量

最新报告期经营现金流为正、资产负债率约在 55-60% 区间（tushare balancesheet 20260630，引擎口径；新端点部分字段被裁剪，精确净现金数据不可用，标注"估算"）。大客户集中+代工模式下，营运资本占用（应收+存货）随营收放大会是常态，现金流质量弱于利润表表现——这是商业模式属性而非恶化信号。

## 第六章：强势点与弱势点

### 6.1 强势点（S）

1. **份额霸主**：GB200 整机柜份额约 69%、GB300 预计 45-50% 仍居第一（研报引述），规模壁垒短期无人可破。

5. **A 股/台股双重定价折价**：母公司鸿海 PE 更低，A 股溢价依赖流动性与叙事。
