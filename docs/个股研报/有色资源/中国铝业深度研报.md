# 中国铝业(601600.SH)深度研报——氧化铝-电解铝一体化的央企平台:口径澄清后的"错杀"与内部对冲机制

> **研究日期**:2026-08-22 | **股价/数据快照**:9.42 元(20260821),总市值 1,616 亿,PB 2.00(51.1% 分位),PE(TTM)11.02(22.3% 分位),TTM 股息率 2.87%(D1)
> **定位**:中铝集团旗下铝业上市平台——"铝土矿(几内亚博法+国内 27.32 亿吨资源)-氧化铝-电解铝-精细氧化铝"全链一体化央企,国内铝土矿产量第一(3,540 万吨/年)(W4)
> **核心逻辑**:本报告的第一个任务是**口径澄清**:2026Q1 中铝归母净利 55.27 亿(+56.35%),而"净利润 100.59 亿"为含少数口径(少数股东损益 45.31 亿,主要归云铝等控股子公司少数股东,W1);H1 预告 112-122 亿(+58-73%)为**归母口径**(W2)——由此推算 **Q2 归母 56.7-66.7 亿,环比 Q1 持平略增(+2.5%~+20.7%)**,并非表面上的环比崩落。60 日 -15.3% 的股价回调(D1)与基本面背离,主因是市场对"氧化铝跌价"的单向担忧:Q1 全国氧化铝均价 2,684 元/吨(-30.5%)确实拖累中铝自有氧化铝板块(2025 年该板块税前盈利 -59.1%、毛利率 35.4%→22.2%,W3),但同一力量使电解铝板块原料降本(Q1 长江铝均价 24,025 元/吨 +17.6%,W5)——**一体化平台的双板块对冲使利润总盘子平稳增长,而市场按"氧化铝受损股"单边定价,形成错杀**。扣非归母 53.6 亿与归母 55.27 亿接近,盈利质量无水分(W1)。引擎判定"上升拐点"(ΔG +1.64),ERP 6.58%(高补偿)。三情景概率加权中枢约 12.0 元(+27%),区间 10.5-13.3 元。

## 第一章:公司概览与股东背景——中铝集团的铝业旗舰

### 1.1 实控人与股东背景

- **实控人:国务院国资委**(通过中铝集团)。中国铝业是中铝集团铝业务的核心上市平台,A+H 双地上市。
- **央企身份的双重性**:信用与资源获取能力(几内亚博法的国家层面矿业协议)是一体化布局的前提;但历史上也曾承担"亏损期托底"的社会职能——2000 年代末行业低谷期的巨亏记忆使市场长期给它"周期折价"。

### 1.2 发展历程(编年史,要点)

| 年份 | 里程碑 | 战略意义 |
|------|--------|----------|
| 2001 | 中国铝业设立,A/H 上市 | 央企铝业平台成立 |
| 2000s-2010s | 氧化铝-电解铝产能扩张;行业低谷期整合(收购多家地方铝企) | 一体化成型 |
| 2017 | 电解铝供给侧改革,产能天花板 4,500 万吨确立(D5) | 存量产能成稀缺资产 |
| 2018-2020 | **几内亚博法铝土矿**:2018-06 签署矿业协议、2018-10 开工、2020-04 投产 | "两海战略"落地,自采率升至 75% |
| 2020s | 精细氧化铝"提级管理";云铝股份(绿色水电铝)整合深化 | 当前阶段 |

(W4 官网/D5;2000s 整合细节为综述,**以年报为准**)

### 1.3 公司定位与业务布局

**一句话定位**:全球级铝全链一体化央企——上游铝土矿(国内资源量 27.32 亿吨/年产量 3,540 万吨居首 + 几内亚博法 1,500 万吨/年)、中游氧化铝(国内龙头)+电解铝+下游精细氧化铝,参控股云铝股份(绿色铝)。

> **核心洞察 1**:中铝的资源端布局(博法矿 17.5 亿吨储量、60 年+开采年限、自采率 75%,W4)使其成为 A 股铝企中**唯一同时持有"矿端(铝土矿)+冶炼端(电解铝)"完整敞口的一体化平台**——这决定了它的利润是"氧化铝/电解铝跷跷板"的两头对冲,而非单一环节的弹性。

> **核心洞察 3**:对冲框架的政策含义——若氧化铝价格因几内亚扰动/行业出清而反转向上,神火/云铝的冶炼利润被挤压,而**中铝的氧化铝板块利润同步回补**;若氧化铝继续阴跌,中铝电解铝板块继续吃降本红利。**两种情景下中铝都不是最差的那一个,但两种情景下它也都不是最强的那一个**——它是一体化的"均值",不是弹性极值。

## 第六章:强势点与弱势点

### 6.1 强势点

1. **资源自给**:博法 17.5 亿吨+国内 27.32 亿吨,自采率 75%(W4)——资源安全维度的独家缓冲;
2. **双板块对冲**:氧化铝/电解铝跷跷板下利润稳定性高于纯冶炼同业(2026 已验证);
3. **估值+股息**:PB 51.1% 分位、PE 11.02(22.3% 分位)、TTM 股息率 2.87%、ERP 6.58%(D1);
4. **央企信用与集团资产**:中铝集团的整合历史与潜在注资通道;
5. **盈利质量**:Q1 扣非≈归母,无水分(W1)。

### 6.2 弱势点

1. **弹性钝化**:对冲结构使它既非最强氧化铝标的也非最强电解铝标的;
2. **少数股东分流巨大**:Q1 少数股东损益 45.31 亿(占净利 45%),云铝等参控股结构稀释归母;
3. **筹码极端分散**:66 万户,上涨合力弱(D1);
4. **氧化铝板块的下行敞口**:2025 板块税前盈利 -59.1%,若继续阴跌仍有拖累(W3);
5. **体量惯性**:大央企的经营调整速度慢于民企同业。

## 第七章:未来发展规划与战略路径

### 7.1 公司披露的战略方向

- **"两海战略"深化**:海外铝土矿资源持续布局(博法为样板)(W4);
- **精细氧化铝提级管理**:高附加值产品结构升级(W3);
- **绿色铝整合**:云铝平台的水电铝协同。

### 7.2 隐含的战略逻辑

"资源为王+对冲为盾":用上游资源锁定成本下限,用双板块结构平滑周期波动,用央企信用支撑逆周期扩张——牺牲弹性换确定性。

### 7.3 机构盈利预期

预告前瞻分 100(D1);全年归母一致预期约 230-250 亿(**估算**,按 H2 与 H1 持平推算);同花顺 F10 盈利预测口径(W5)。
