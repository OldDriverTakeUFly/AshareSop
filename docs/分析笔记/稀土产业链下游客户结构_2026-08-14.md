# 稀土产业链下游客户结构速览（4 标的）

> **研究日期**：2026-08-14 | **用途**：北方稀土/金力永磁/盛和资源/中国稀土 4 篇深度研报的共享素材 + 下游客户结构速答
> **数据来源**：各公司 2025 年报/2026 中报预告（具名 URL 见文末）、公司投资者关系活动记录表、商务部公告、行业协会数据

## 一、稀土产业链全景与消费结构

```
上游采矿 → 冶炼分离 → 功能材料 → 终端应用
白云鄂博(轻)/南方离子矿(中重)/海外(MP等)
          ↓
   稀土氧化物/金属（氧化镨钕/镝/铽…）
          ↓
   钕铁硼磁材(占消费40%+)/催化/抛光/储氢/荧光
          ↓
   新能源车/风电/变频空调/机器人/消费电子/军工
```

**中国稀土消费结构**（中国稀土行业协会《稀土功能材料 2035 发展战略研究》+ 东财研报）：

| 应用领域 | 占比（约） | 说明 |
|---------|:---:|------|
| 永磁材料（钕铁硼为主） | **40%+** | 最主要增长极；烧结钕铁硼占永磁产量 95.1% |
| 催化材料 | ~20% | 石油裂化催化剂、汽车尾气催化剂 |
| 抛光材料 | 10-13% | 面板/半导体抛光粉 |
| 冶金机械 | 5-8% | 稀土合金、球化剂 |
| 储氢合金/荧光等 | 其余 | 镍氢电池、荧光粉 |

> 全球口径（vs 中国口径）：永磁 ~29%、催化 ~20%、抛光 ~13%——中国磁材占比更高（中国占全球稀土永磁制造 **94%**，IEA 2024 统计，引自金力永磁 2025 年报摘要）。

## 二、4 标的在产业链中的位置与客户结构

### 2.1 北方稀土（600111.SH）——轻稀土原料商，客户 = 磁材厂

| 维度 | 内容 |
|------|------|
| **产业链位置** | 上游冶炼分离 + 功能材料一体化（轻稀土绝对龙头，2025 年开采配额占全国轻稀土大头） |
| **产品结构** | 稀土原料（精矿/氧化物/金属，核心为**氧化镨钕**）+ 稀土功能材料（**磁材合金甩带片** 2025Q2 产量 1.8 万吨创新高、储氢材料、抛光粉） |
| **直接客户** | **国内头部磁材企业大部分**——中科三环等皆为主要客户（公司投资者关系记录表，2026-07-21）；金力永磁等磁材厂与其建立长期战略合作 |
| **销售模式** | **长协为主**；公司挂牌价曾是行业/全球供应链价格风向标；2022 年起供货协议约定磁材厂生产废料（磁泥/边角料）**返还北方稀土**（回收再分离） |
| **上游** | 精矿**独家采购自包钢股份**（白云鄂博尾矿，关联交易定价）——北方稀土同时是包钢股份最大客户 |
| **终端传导** | 经磁材厂间接覆盖新能源车、风电、变频空调、工业电机 |
| **关键数据** | 2025 营收 425.63 亿（+29.11%）、归母净利 22.51 亿（+124%）；2026H1 预告净利 19.8-20.6 亿（**+112.74%~121.33%**，量价齐升）；氧化镨钕均价 2025 年初 39.8 万→年末 45.4 万/吨（+14%） |

### 2.2 金力永磁（300748.SZ / 06680.HK）——磁材厂，客户 = 终端品牌/电机厂（客户结构最透明）

| 维度 | 内容 |
|------|------|
| **产业链位置** | 中游高性能钕铁硼磁材龙头（晶界渗透技术），H+A 双上市 |
| **2025 下游收入** | 总营收 77.18 亿（+14.11%）、主营 70.28 亿（+19.00%）：**新能源汽车及零部件 39.41 亿（~51%）**、节能变频空调 19.17 亿（~25%）、风电 4.88 亿（~6%）、机器人及工业伺服电机（2024:1.96 亿）、3C（2024:2.13 亿） |
| **区域结构** | 境内 64.47 亿（+16.36%）/ **境外 12.70 亿（~16.5%）** |
| **客户集中度** | 前五大客户占 45.08%（2025）；第一大客户"客商A"11.05 亿（~14%，2024 为 8.31 亿） |
| **具名客户** | **特斯拉**（2020-09 签采购协议，一级供应商）、**比亚迪**（一级供应商）、联合汽车电子、博世（多年零部件磁钢）；变频空调覆盖**全球前十大压缩机厂中的八家**（美的/格力供应链）；风电：金风科技（2009 年曾参股金力永磁，金风投资控股为股东）、西门子歌美飒；终端延伸上汽/北汽/蔚来/理想 |
| **股东绑定** | 赣州工业投资控股、金风投资控股为股东（产业链资本绑定） |
| **关键数据** | 2026H1 预告净利 4.0-4.6 亿（+31.17%~50.84%）；研发 5.06 亿（+57.6%，占营收 6.55%）；2025 磁材毛坯产销创新高；产能规划 2025 年 4 万吨 |

### 2.3 盛和资源（600392.SH）——稀土+锆钛双链，全球化资源商

| 维度 | 内容 |
|------|------|
| **产业链位置** | 稀土采选/冶炼分离/金属加工/废料回收 + 锆钛选矿；**海外资源布局最深**（参股美国 Mountain Pass 矿 MP 公司、收购非洲资源公司、连年盈利穿越周期） |
| **2025 收入结构** | 总营收 149.91 亿（+31.83%）、归母净利 8.39 亿（+304.94%）：**稀土产品 141.07 亿（占 94.10%，毛利率 11.12% +6.57pp）**、锆钛及其他 8.14 亿（5.43%，毛利率 2.80%） |
| **直接客户** | 下游磁材厂与贸易商为主（年报披露"贸易业务前五名销售客户"但具名名单需原文核实——**未获取，不编造**）；独居石进口加工 |
| **历史包销关系** | 中国稀土（000831）过往矿源曾通过盛和资源**包销**至国内（东财研报 2025-02） |
| **2026H1 预告** | 净利 8.0-9.3 亿（**+112.25%~146.75%**），价格驱动 |
| **规划** | 2026-2028 拟投 30 亿+ 加码"稀土+锆钛"；锆钛营收占比目标 30%+；2025 收购江阴加华（离子型稀土分离） |

### 2.4 中国稀土（000831.SZ）——中重稀土平台，客户 = 磁材厂/军工配套

| 维度 | 内容 |
|------|------|
| **产业链位置** | 中国稀土集团旗下上市平台，**中重稀土**（南方离子型矿）冶炼分离，"北轻南重"双寡头之"南"（集团拥有 62 宗矿业权，2022 整合 72 家矿山/33 家冶炼分离企业） |
| **产品结构** | **稀土氧化物为第一大收入**（2025 收入 23.74 亿，+30.81%；总营收 31.82 亿 +5.11%）；稀土金属 2024 成本占比 44.43%；核心产品氧化镨钕/氧化镝/氧化铽，99.999% 高纯分离能力；2024 前三季已分离氧化镨钕 881 吨 |
| **直接客户** | 国内磁材厂（全国约 200 家钕铁硼企业）+ 冶炼分离企业；终端经钐钴/高矫顽钕铁硼延伸至**军工配套磁材供应商** |
| **中重稀土终端** | 镝/铽 = 高性能钕铁硼**不可替代的耐高温添加剂**（氧化镝 60-65% 需求来自钕铁硼）；钐钴永磁（军工耐高温电机）；核反应堆控制棒、磁光材料 |
| **政策变量** | 2025-04 商务部 18 号公告对钐钆铽镝镥钪钇 7 类中重稀土物项**出口管制**（含含镝钕铁硼磁体）；2025-10 第 62 号公告扩展至磁材制造技术→战略价值重估 |
| **2026H1** | 归母净利 2.37 亿（**+46.53%**，8-14 披露当日涨停）；整合注入预期为市场核心叙事 |
| **价格背景** | 2025-06 氧化镝 161.5 万/吨（同比 -11.26%，缅甸/澳洲供应增加）；2025 开采配额：离子型（中重）指标 **-11.1%**，轻稀土微增 |

## 三、客户结构对比总结（谁在买、在哪、占多少）

| 标的 | 卖什么 | 直接客户 | 客户在哪里 | 集中度/占比 |
|------|--------|---------|-----------|------------|
| 北方稀土 | 氧化镨钕等原料+甩带片 | 磁材厂（中科三环、金力永磁等头部全覆盖） | 国内为主（长协） | 长协为主，挂牌定价；上游独家绑定包钢 |
| 金力永磁 | 高性能钕铁硼磁钢 | 车企/电机/压缩机/风机厂：特斯拉、比亚迪、博世、联合电子、美的格力链、金风、西歌 | 境内 64.5 亿 / 境外 12.7 亿（16.5%） | 前五大 45.08%，第一大 ~14%（客商A 11.05 亿） |
| 盛和资源 | 稀土氧化物/金属/精矿 | 磁材厂+贸易商（名单未披露） | 国内+海外资源端（美国 MP 参股） | 稀土占收入 94.1% |
| 中国稀土 | 中重稀土氧化物/金属（镝铽） | 磁材厂（约 200 家）+军工配套 | 国内为主；出口受管制约束 | 稀土氧化物为第一大收入（23.74 亿） |

> **核心洞察**：产业链的"钱"从终端流向——新能源车（金力永磁 51% 收入）> 空调（25%）> 风电（6%）。稀土涨价周期中，越上游越受益（北方稀土/盛和净利 +113~305%），磁材厂利润被挤压后靠顺价能力维持（金力永磁 +31~51%）。**北方稀土与金力永磁互为上下游**，是观察产业链利润分配的最优样本对。

## 四、催化剂与风险（4 标的共享）

**催化**：①稀土价格上行（氧化镨钕 2025 年 +14%，2026 续涨）②开采配额收紧（2026 氧化镝指标 -15%）③出口管制强化战略价值（2025-04/2025-10 两轮）④中报集体预喜（上游 +113~147%）⑤人形机器人磁组件需求预期

**风险**：①缅甸/澳洲/美国海外新增供给（MP 扩产）②镝铽价格已处历史高位（2025 年镝价同比 -11.26% 显示波动）③磁材厂成本传导失败则需求反噬 ④配额政策变化 ⑤中国稀土 PE 237 的估值风险
