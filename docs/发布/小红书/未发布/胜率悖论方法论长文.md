**标题**:胜率七成四、盈亏比四比一,十三个月白干😵

**tags**:#量化 #交易纪律 #风险管理 #方法论

**正文**:

先看一张教科书级的成绩单:二百二十七笔交易,胜率七成四,盈亏比四比一,平均每笔
赚四个多点。任何一个量化教材都会告诉你,这是印钞机的参数。

真实结局:十三个月下来,累计收益约等于零。中间一度浮盈接近五成,然后一个月之内
全部回吐,终点几乎回到起点。

发生了什么?选股没有变差——胜率还是那个胜率,盈亏比还是那个盈亏比。出问题的是
另一头:某一个月份,单月亏掉三成一。解剖那一个月,发现它不是由很多笔小亏损组成的,
而是三笔深亏叠在一起,最大单笔亏了三十多个点。进一步追,这三笔的共同点是同向:
同一天开的三只,后面一起吃了连续跌停,想出出不去,只能被动穿越整段崩塌。

这才是悖论的答案:胜率乘盈亏比,描述的是"平均每一笔"的世界;而账户的生死,
由"最坏的那些天如何挤在一起"决定。前者是分布的形状,后者是分布的尾部相关性——
它们互相独立,可以一个很漂亮、一个很致命。我们原有的两道风控,连亏熔断和单日亏损
上限,全是为"亏损互相独立"设计的;对"三只同涨同跌"的相关性尾部,它们形同虚设。

三条启示。其一,评估任何策略,别只看胜率和盈亏比,先问它历史上最惨的一个月
亏了多少、那个月里亏损是怎么聚在一起的。其二,警惕"同源持仓"——如果几笔持仓的
理由本质上是同一个(同题材、同方向、同一天触发),它们就不是三笔分散的风险,
是一笔三倍大的风险;同日新开数量必须设上限。其三,单票权重上限要在"最坏单笔"
的尺度上倒推:如果一种形态可能单笔亏三成,那只让它占据组合的一成多,亏了也伤不了
筋骨。

后来我们给这套研究组合加的三道约束,全是围绕尾部设计的:同日新开不超过两只、
单票权重封顶两成、被锁住的持仓逐日挂账——不是为了让成绩变好,是为了让"最坏的那个月"
变得可生存。

方法论一句话:均值形状决定你赚多快,尾部相关性决定你能不能活到赚——先活下来,
再谈印钞机。
