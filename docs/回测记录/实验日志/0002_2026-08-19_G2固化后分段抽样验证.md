# 0002: G2 固化后分段抽样验证（2026-08-19）

## 1. 思路来源

用户要求：G2 固化后不能只看五年总量（+126.4%/1.081），要做抽样检测——
在牛市段/熊市段/牛熊切换段/随机段分别对比 G2 vs 前G2基线，
看 G2 是**总是**优于基线，还是只在平均意义上占优（可能掩盖"某些状态下大幅劣化"）。

这是对 0001 结论的稳健性检验：五年总量好 ≠ 每种市场状态下都好。
特别要回答：2026 年 -8.2pp 的倒退是局部代价还是系统性问题。

## 2. 假设

- H1：牛市段 G2 显著优于基线（放松机制的正面战场）
- H2：熊市段 G2 与基线完全一致（放松条件 bull+MA200上 在熊市不触发，不变量）
- H3：切换段 G2 大概率优于基线但方差大（取决于切换方向）
- H4：随机段 G2 平均占优但不全胜——如果出现大幅劣化段，需要定位原因

## 3. 实验设计

- 选段规则**事前程序化**（防止挑数字）：全部 80 交易日窗口按 10 天步长滑动，
  计算每窗 bull%/bear%/MA200上%/regime翻转数；牛市段 = bull%×MA200上% top3，
  熊市段 = bear%×(1-MA200上%) top3，切换段 = 翻转密度 top3（三类互不重叠），
  随机段 = seed=42 抽 4 段（60-120 交易日）。
- 每段独立冷启动回测（100 万初始资金，同 universe 同配置），
  base = `bull_relaxed_buy_momentum=0.0`，g2 = `60.0`。
- 不变量检查：纯熊段（可放松日=0）两变体交易序列应完全一致。
- 判读标准（事前）：G2 胜率 + 单段最大劣化幅度。若任一段劣化 >8pp 需机制定位后才算通过。
