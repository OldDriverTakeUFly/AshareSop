# 0010: 滚动宇宙 G2 口径验证——实盘切换前置实验(2026-08-31)

## 1. 思路来源

用户拍板盘中轮动选股基准从 top20(动量阶段产物)切到 G2(「直接用 G2 筛选买入池」)。
阻塞点:G2 生产基线(gx_G2_bull60)的五年验证(+126.40%/MDD15.6%/Sharpe1.081)用的
是 **2021-01-04 冻结的 top200 宇宙**;实盘/盘中线必须用**滚动宇宙**(T-1 成交额 topN)。
切换前须验证宇宙口径不翻转结论(2026-08-30 立项,判定线事前定稿并预注册于
`docs/superpowers/prompts/0010_cron_prompt.md`,2026-08-31 18:30 cron 收尾机械执行)。

## 2. 假设

- H1: 滚动宇宙(T-1 成交额 top200,季度刷新)下 G2 的五年结论不翻转——R_q200 落在
  采纳线内(Sharpe>1.0 且 收益≥100% 且 MDD≤17% 且无一年倒退>5pp)。
- H2(隐含,被证伪):宇宙口径(冻结 vs 滚动换血)对 G2 十道闸选出的票质量影响有限。
- 敏感性:月频(R_m200)/池宽 300(R_q300)与主变体方向大体一致(Sharpe≥0.9)。

## 3. 实验设计

- 变体(基线=冻结宇宙 G2,不重跑,数字复用 0001 固化档):
  - **R_q200** — 季度滚动 top200(主变体,实盘口径)
  - **R_m200** — 月度滚动 top200(敏感性:滚动频率)
  - **R_q300** — 季度滚动 top300(敏感性:池宽)
- 宇宙构造(`scripts/abx/rolling_universe_g2_abx.py`):每段首 ref=前一交易日,
  `daily_price` 按 amount 排序取 topN(close>0 且 vol>0);**每段宇宙 = 滚动 topN ∪
  当前持仓**(持仓保留因子分,防跌出宇宙后动量崩塌卖出永不触发、持仓卡死)。
- BASE 参数与 gx_G2_bull60 生产配置逐项一致(max_positions=5 / buy_momentum=70 /
  bull_relaxed_buy_momentum=60 / 十道闸全套,见脚本 45-60 行)。
- 窗口 20210104→20260731,初始资金 100 万,账户 `ru_{label}` 入口 reset 重跑覆盖。
- 烟测(2021Q1,仅 R_q200):-3.63% vs 冻结同期 -3.47%,口径一致性通过。
- 判定线(事前预注册):采纳=R_q200 Sharpe>1.0 且收益≥100% 且 MDD≤17% 且无一年
  倒退>5pp;**否决=Sharpe<0.9 或 MDD>18% 或任一年倒退>8pp**;中间=条件采纳。
  稳健性哨兵:R_q200 Sharpe>1.4(异常好)→先做前视审计;敏感性变体方向相反→降一档。
- 运行:08:51 脱离会话启动(长回测规范),逐变体落盘;三变体 6.9h 全部完成
  (15:47 收尾,早于 18:30 收尾 cron),日志 `logs/abx/rolling_universe_run.log`,
  结果 `logs/abx/rolling_universe_g2_abx.json`。

## 5. 决策

**❌ 否决(2026-08-31 18:30 按预注册判定线机械执行)——三条否决线全中**:

- Sharpe **-1.004** < 0.9 ✓
- MDD **60.35%** > 18% ✓
- 最差年度倒退 **-48.78pp**(2021)> 8pp ✓

哨兵不触发(Sharpe 远低于 1.4,无需前视审计);敏感性变体 R_m200/R_q300 方向与
R_q200 **一致**(全部深负、无一满足敏感性支持线 Sharpe≥0.9),不构成反向证据,
无降档问题。烟测(2021Q1 -3.63% vs -3.47%)与全期结论的巨大反差见下文机制解读①。

按预注册分支:D1=否决 → **停止后续步骤**(G2 信号导出/调度挂载/g2_shadow 账户均
不执行),轮动代码零改动,遗留「实盘宇宙方案重设计」。

**负结果的机制解读(事后假说,标注未验证;比结论本身更重要)**:

1. **烟测为何没暴露**:烟测窗口(2021Q1)内滚动宇宙与冻结宇宙**逐码相同**——index_daily
   起于 20210104,首段 `ref=prev_trading_day(20210104)` 返回 None 回退为段首日本身
   (`ref = prev_trading_day(s) or s`),滚动首段与冻结快照同日同查询(收尾后复核确认,
   见 §4 末核查补记);-3.63% vs -3.47% 的 0.16pp 差全为路径噪声,宇宙差异自 Q2
   换血才开始累积(0009 教训的又一变体:短窗烟测只验机制,不验路径)。
2. **成交额 top 池的「高位吸入」**:A 股放量上涨的股票会自动挤进当期成交额 topN——
   滚动宇宙在每段首高位吸入「当季最热」,十道闸放行的动量>70 票大量是刚暴涨过的
   高波动焦点票,段内买入后均值回归;季度刷新=反复在顶部接力。冻结宇宙不刷新,
   闸门在同一批票上反复筛选,自然规避了该循环。
3. **冻结基线的宇宙依赖性 caveat(反向)**:G2 的 +126.4% 显著依赖「2021-01-04 快照」
   这一特定宇宙抽样。不推翻 0001/0002 在该宇宙内的固化结论,但**实盘映射时宇宙
   方案是第一性问题**——G2 的 edge 目前只在冻结快照口径下成立。
4. 月频好于季频(-37.4 vs -52.2)、宽池好于窄池(-42.0 vs -52.2):方向上「换血
   冲击被摊薄则伤害减轻」,但无一接近冻结口径,参数微调无解,需改宇宙方案本身。
