# 0011: 幸存者剪枝修复与基线重锚——冻结/池宽/滚动三腿复测(2026-09-01 启动,09-03 跑完,09-09 归档)

## 1. 思路来源

0010 数据层核查发现:`daily_price` 退市股历史整体缺席(幸存者剪枝),回测宇宙天然
只含存续股。用户拍板修复方案:退市数据放独立库,**仅在研究上下文临时混入**,
实盘链路物理不可调取;配套引擎退市强平规则。修复后重锚基线并复测 0010 主变体。

## 2. 假设

- H1: 修复后冻结基线下修(退市股挤占宇宙名额 + 若被买入则承受真实退市损失)。
- H2: 滚动口径受幸存者影响更大(逐季吸入退市股,0010 已证 -52.2% 是偏乐观下界)。
- H3: 池宽 200→500 的效应待测(干净对照:同数据同代码仅 TOP_N 不同)。

## 3. 实验设计

- **数据修复**(commit 5a41630):退市股 255 只有数据(42.8 万行日线,adj_factor 按日
  合并;84 只空返回均为 2015 前退市老代码)+ 全市场 namechange 13,832 行(含 2,789
  行 ST 名)→ 独立研究库 `storage/database/market_data_delisted.db`。
- **混入机制**:`market_db.get_connection` 新增 `MARKET_DB_ATTACH_DELISTED=1` 钩子
  ——连接级 TEMP VIEW 遮蔽 daily_price(UNION ALL),连接关闭即蒸发;生产进程不设
  变量物理不可见;视图不可写防误写。实测开销:点查 +0.6ms/连接、区间扫描 +1ms、
  行榜 +6ms、DISTINCT +0.35s/次——对回测日耗 <0.5s,可忽略。
- **退市强平**:`executor._force_exit_terminated_holdings`(run_day 前):持仓为
  list_status='D' 且当日无行情 → 按最后收盘价卖出,reason 标注退市强平;停牌(L)
  不触发;查不到末价(生产库剪枝)仅告警。烟测通过(002619.SZ 按真实末价 0.56 出清,
  -22% 真实损失入账,活股零影响)。
- **三腿**(均 G2 生产参数,窗口 20210104→20260731,脱离会话链式运行):
  1. refix_frozen_u200 — 冻结 top200 重锚(vs 旧 +126.40%/15.6%/1.081);
  2. refix_frozen_u500 — 池宽探针(无旧对照);
  3. refix_ru_R_q200 — 季度滚动 top200 复测(vs 0010 剪枝口径 -52.20%/60.35%/-1.004)。
- 判定:滚动复测沿用 0010 预注册否决线,不新设事后线。已知口径限制:退市股仅回补
  价格+adj_factor,未回补财务(daily_basic/financial)——预期多数退市股过不了因子闸。

## 5. 决策

1. **0010 滚动否决维持**:refix 滚动 Sharpe -1.044<0.9、MDD 62.96>18、年度倒退
   远超 8pp——三线仍全中。幸存者净效应(滚动口径,漂移窗口仅 2-3 天,近洁对比):
   **-2.4pp 收益 / +2.6pp MDD**,即名额挤占通道的量级——小而真实。
2. **冻结 -66.4pp 位移主因=数据版本漂移,非幸存者**(证据链):
   - 成交路径首笔即分歧(旧 2021-03-12 买 600111.SH;refix 首日即买 601901.SH
     方正证券+601995.SH 中金)——首日闸门翻转与退市股无关;
   - **受控评分实验(09-09)**:同码集 199 只,view 开/关因子分**零差异**——评分
     纯按码计算,无横截面污染,TEMP VIEW 洗清嫌疑;
   - 漂移通道实锤:实验过程本身触发大量「Refreshing dividend history」(缓存 TTL/
     缺失 → API 重取)——8-18 与 9-1 的缓存状态差异改变因子分(601901.SH 现势
     momentum 82.3 过闸,旧势未过)。
   - **方法论新警告:基线不可复现**——+126.4% 只在 8-18 的缓存快照上成立。0010 的
     「宇宙依赖性」需加姊妹条「**数据版本依赖性**」:任何跨时间的结果比较必须
     标注缓存版本,重大结论前应同日重跑对照。
3. **池宽 200→500 显著退化(同数据同代码,H3)**:+60.0→+20.8(Sharpe 0.716→0.363,
   MDD +3.5pp)。G2 的优势高度集中于「时点成交额 top200 这一狭窄档位」——与 0010
   滚动崩盘合并看:既不是越热越好(滚动追热崩),也不是越宽越稳(500 摊薄退化),
   top200@时点恰好承载优势 → 宇宙依赖性第三证。
4. 强平规则保留(设计正确性由烟测保证;财务回补后自然激活)。
