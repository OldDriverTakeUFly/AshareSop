# 0012: 双随机测试台——随机宇宙×随机窗口,G2 优势的宇宙依赖性诊断(2026-09-11)

> 状态:预注册+首夜 u200 臯运行中(16 trials);§4-6 待结果后填写。
> 脚本: scripts/abx/random_universe_0012.py;数据版本 daily_price@20260831(启动时记录)。

## 1. 思路来源

0010 证滚动成交额宇宙崩盘(-52.2%)、0011 证池宽退化(200→500:+60→+20.8)与数据
版本漂移(-81.7pp)——三条证据共同指向 G2 的优势高度依赖特定宇宙口径。但 0003
测试台只随机化了**时间窗与固定池内截断**,从未随机化**宇宙归属本身**。本实验把
宇宙成员变成随机变量(全市场资格抽样,含退市股),配随机窗口,度量 G2 优势是否
稳健、对何种池型成立。用户需求(2026-08-31 讨论):①差异化数据防过耦;②固定
板块/全随机两种生成;③池宽 200 vs 500 对比;④输出策略/基线/Sharpe/峰值/回撤;
⑤幸存者数据纳入(0011 已落地)。

## 2. 假设

- H1(防守稳健):bear 状态下策略-池EW 日度配对差值稳定为正——G2 的防守优势
  不依赖特定宇宙。
- H2(参与不损):bull 状态高参与 trial 的配对差值不为显著负。
- H3(池宽):200/500 两臂同窗配对下,分状态配对差值无系统性差异(若 500 更优,
  与 0011 冻结池宽结论形成张力,提示"随机池+宽"优于"成交额窄档")。
- H4(退市样本):随机池含退市股(期望 ~9 只/200)但 0 买入(财务缺失),池EW
  承受其退市损失而策略天然规避——差值因此含~小额"幸存者红利"(口径限制,判读时
  剥离说明,非策略能力)。

## 3. 实验设计(预注册,2026-09-10 定稿)

- **抽样**:seed=2026;窗口 60-180 交易日(起点间距<40 重抽),源 20210104→20260731;
  池=窗口起点时有行情([W-10,W])且上市满 3 年的 L+D 全体中随机抽 N(u200/u500,
  两臂共享窗口序列);排除显式记账(次新/无 stock_basic)。
- **基线(预注册)**:同池等权持有(池EW,自算;停牌/退市冻结于最近可得价)。
- **变体**:G2 生产参数(与 0010/0011 完全一致),唯一自由度=宇宙与窗口。
- **退市口径(0011 沿用)**:MARKET_DB_ATTACH_DELISTED=1,退市股占池名额、计入
  池EW,但不送打分(无财务过不了因子闸,行为等价;免空结果逐日重取)。
- **判读纪律(事前,不可事后改)**:
  1. 主判据=分状态日度配对差值(bull/bear/neutral 各报胜率/均值/中位 pp/日);
     原始混合胜率只显示不判读(0003 教训:暴露口径不对等)。
  2. 参与度(有持仓天数占比)<20% 的 trial 标「暴露不足」单独归类。
  3. 结论形态:bear 差值稳定为正(胜率>60% 且均值>0)=H1 成立;bull 高参与且
     均值≥-0.1pp=H2 成立;全状态无稳定正差=G2 优势宇宙依赖坐实,实盘宇宙方案
     须回答「top200@2021 为何特殊」。
  4. 负结果照写;诊断性实验,无采纳/否决参数变更。
- **运行节奏**:首夜 u200×16 trials(池宽序贯设计:u500 臂数量视 u200 离散度定);
  脱离会话,逐 trial 落盘 logs/abx/random_universe_0012_{arm}.json。
- **性能修复(本实验前置,已落地)**:①vol_ratio 两步取数(0011);②
  _compute_stock_20d_drops 标量子查询 MAX+vol>0 在 TEMP VIEW 下全历史扫描
  (~10s/次)→纯索引两步;实测随机池日耗 76→29.1s/天。

## 5. 决策(按预注册纪律判读,u200 臂)

1. **H2 证伪(最重结论)**:bull 状态 0/16 正均值、-0.36pp/日——且这**不能全归暴露
   口径**:参与度 97% 的 trial(#16 bull -0.31、#5 -0.23、#7 -0.32)满仓仍在牛市日
   跑输随机池,是**选股层拖累**而非持币拖累。0003 的「上涨窗参与度」病灶在随机
   宇宙层面复现且更重——G2 的十道闸在随机池里选出的票,牛市里跑不赢池子平均。
2. **H1 未通过严格线**:bear 均值 +0.274pp/日但 trial 胜率 8/15(53%<60%)、中位仅
   +0.01——正差高度集中在 **2024-2026 时代的熊窗**(#8 +1.28/#10 +0.92/#12 +0.73/
   #3 +0.67/#1 +0.60),2021-2022 熊窗无防守优势(-0.05~-0.18)。防守优势存在但
   **分时代**,非宇宙无关的稳健性质。
3. **H4 机制确认**:退市股 6.2/池、0 买入、池EW 承接其损失——差值内嵌小额幸存者
   红利(策略天然不买死票),判读时已知并未剥离,量级受退市占比(~3%)限制。
4. **综合判定:G2 优势宇宙依赖坐实(第四证,与 0010/0011/0003 闭合)**——在随机
   宇宙上,G2 是净拖累(-10.1pp/窗,牛市日 -0.36pp/日),防守仅存于特定时代;
   其优势本质上绑定「**成交额头部窄档 + 2024 后时代的防守闸门**」。用户原始担忧
   (策略与特定数据库过耦的假最优解)从第四个角度获得定量证据。
