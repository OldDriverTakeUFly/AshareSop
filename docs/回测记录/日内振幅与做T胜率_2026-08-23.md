# 日内振幅对做T胜率的影响校验

**日期**: 2026-08-23
**数据**: 59 只模拟盘持仓宇宙 × 254 交易日（2025-08-01 ~ 2026-08-18），14,312 个股票日 / 717,264 根 5 分钟 bar
**模块**: `davis_analyzer/intraday/amplitude_study.py`（CLI: `python -m davis_analyzer.intraday amp`）
**明细**: `intraday/reports/amp_study_summary_20260823_232947.csv`（30 变体 × train/holdout/all）、`amp_study_days_20260823_232947.csv`（逐笔）
**纪律**: 训练窗 2025-08~2026-04 扫描，留出窗 2026-05~2026-08 只终验（沿用第二轮 gap_smart 验证切分）；往返成本 45bps

## 一、研究设计与防前视

三个因果可用的 T-1 振幅代理（`features.py` 本轮扩充导出，均有单测）：

- `prev_amp`：前一日振幅 (high−low)/pre_close（shift 一日）
- `atr5` / `atr20`：前 5/20 日平均振幅（rolling + shift 一日）
- `norm_gap`：当日跳空深度 / atr20（09:35 时点可得，下跳空为负）

对比口径：`amp_t`（当日实际振幅）**只能在事后看到**，用它分桶是描述性证据，不能当交易依据。

## 二、A：振幅高度可预测——但这是"机会池"属性，不是"胜率"属性

| 代理 | spearman(amp_t, 代理) |
|---|---|
| atr5 | **+0.733** |
| atr20 | +0.708 |
| prev_amp | +0.668 |

波动聚集效应在 A 股个股层面非常强。按 atr20 五分位看次日机会（n≈2,626/桶）：

| atr20 分位 | 次日平均振幅 | P(次日振幅≥3%) | 完美上限中位 |
|---|---|---|---|
| Q1 | 1.93% | 12% | **+78bps** |
| Q2 | 2.90% | 36% | +145 |
| Q3 | 3.73% | 58% | +201 |
| Q4 | 4.82% | 79% | +275 |
| Q5 | 6.93% | 95% | **+434bps** |

**结论 A**：振幅可预测且单调拉开机会池——Q1 的完美上限中位（+78bps）扣除 45bps 成本后几乎无肉，**低预测振幅的股票日在结构上不适合做T**；Q5 是做T利润的集中地。

## 三、B：当期振幅与做T盈亏强相关（事后分桶，非因果）

按 amp_t 五分位（n=63~716/格）：

| 策略 | Q1(低振幅) | Q3 | Q5(高振幅) |
|---|---|---|---|
| gap_down_long@3% | −58bps / 胜率24% | −100 / 35% | **+234 / 72%** |
| gap_smart(现行配置) | −73 / 7% | −46 / 38% | **+261 / 78%** |
| amp_grid@5%/1.5%x2 | +7 / 47% | +20 / 51% | **−140 / 38%** |

**结论 B**：高振幅日是 gap 类（低吸反转）策略的利润来源、低振幅日是绞肉机（成本吃光反弹）；**网格完全相反**——大振幅日（趋势日）单向击穿网格，EOD 轧平放大亏损。振幅对做T"有没有影响"的答案是**决定性的**。

## 四、C：因果门控——预测振幅不能直接换胜率

### C1 按 atr20（T-1 可得）分桶的基线策略：非单调

gap_smart@3%/x14:00（无过滤，n=300）：Q1 **+87** / Q2 +12 / Q3 −17 / Q4 **+160** / Q5 −1（bps，均值）。
两头好中间平：低波动票上的 3% 低开是"异常事件"（反转强），高波动票上则常见（无信息）。**预测振幅与当期振幅对策略的作用不同向，简单门控没有稳定的单调收益**。

### C2 门控变体终验（关键行，全窗 / 留出窗）

| 变体 | all: n/胜率/mean | holdout: n/胜率/mean | 判读 |
|---|---|---|---|
| smart（现行获胜配置） | 127 / 55.1% / +79 | 26 / 57.7% / +108 | 基线 |
| smart+atr20_min=2% | 127 / 55.1% / +79 | 26 / 同左 | **零操作** |
| smart+prev_amp_min=5% | 101 / 57.4% / +80 | 24 / 58.3% / +95 | 换代理仍无实质提升 |
| g3x 基线（无过滤） | 300 / 50.0% / +43 | 77 / 40.3% / −6 | 体制脆弱基线 |
| g3x+norm_gap_min=−1.0 | 201 / 51.7% / +35 | 63 / 44.4% / +7 | 留出窗 +13bps/胜率+4pp，弱 |
| g3x+norm_gap_min=−0.7 | 105 / 55.2% / +49 | 33 / 48.5% / +17 | 同向但阈值后验、n 小 |
| smart+norm_gap_min=−1.5 | 119 / 56.3% / +81 | 26 / 同基线 | 留出窗全通过，无操作 |
| grid@10%/5%x3 | 323 / 46.1% / +45 | 132 / 43.9% / +52 | 双窗同向但**中位 −32、胜率 46%**（右尾彩票型） |
| grid@15% 族 | — | — | 训练窗为负、留出窗为正，**符号翻转** |

**为什么 atr20 门控是零操作**：诊断显示 g3x 触发日的 atr20 中位 **5.77%**（P25 4.58%）vs 全宇宙中位 3.62%——**3% 低开触发本身已经自选了高波动股票**，再叠振幅门槛剔不掉任何交易（smart 127 笔中 atr20_min=2% 只字未动，min=3% 仅剔 2 笔）。

### 影子验证 08-19 旁证（10 笔全亏 −210~−449bps）

唯一可完整计算的样本 688981.SH：norm_gap **−0.55σ**（浅跳空）、atr20 5.5%（高波动）——**任何振幅门控都拦不住它**。飞刀日的解药是体制过滤/止损，不是振幅。（保留意见：`daily_price` 对该批股票历史有空洞，9/10 只无法计算 atr20，此旁证仅供参考。）

## 五、结论

1. **日内振幅对做T的影响是决定性的**——它划定机会池（atr20 Q5 完美上限 +434 vs Q1 +78，成本 45bps）并主导策略分化（gap 吃高振幅、grid 死于高振幅）。且振幅可预测性极强（spearman 0.73）。
2. **但"基于振幅的门控体系"不能提升现行策略胜率**——三个原因：触发自选高波动（门控零操作）；因果分桶非单调（预测振幅≠当期振幅）；norm_gap 标准化方向训练窗有效、留出窗不稳健。扫描 30+ 变体没有一个在留出窗显著超越现行 smart 配置。
3. **振幅的正确角色是"必要条件/容量规划"，不是"胜率开关"**：
   - 选股/底仓层：做T 只值得在 atr20 ≥ ~2% 的票上铺底仓（Q1 的票做T是给券商打工）
   - 策略层：胜率的已验证杠杆仍是 **trend_up 体制过滤**（留出窗 +108 vs 裸 −6），振幅信息已被触发条件隐含
4. **grid 系判定**：与"前日振幅→网格"的直觉相反，真正杀死网格的恰是高当期振幅日（Q5 −140bps）；参数域不稳定（@15% 训练/留出符号翻转），维持首测"保留观察、不上线"结论。

## 六、诚实声明与下一步

1. 多重比较风险：~30 个变体、留出窗 n=19~132；本文所有"无提升"结论比"弱提升"结论可靠（零效应不需要多重比较校正）
2. 单一自然年 + 宇宙=模拟盘持仓（持仓本身是趋势/景气筛选后的存活者，振幅分布偏高）；2026-05~08 留出窗为单边下跌市
3. norm_gap 阈值（−0.7/−1.0）系扫描后选定，需第二个样本外窗口或影子台账积累后复验
4. 下一步建议：影子台账继续按预注册标准积累（≥30 笔再判定）；若要做振幅方向的增量研究，优先"底仓池 atr20 分层容量规划"而非入场过滤；`daily_price` 空洞股票的历史回补完成后可重算 0819 旁证
