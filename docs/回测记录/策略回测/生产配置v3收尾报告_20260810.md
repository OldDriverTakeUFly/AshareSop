| PE 过滤（80/60/50） | 无差异/更差 | 动量前置过滤已筛掉高PE |

| 技术因子/自适应卖出/动态权重/Amihud/龙虎榜/回购 | 均失败 | 见 docs/方法论/因子研究 |

## 四、关键方法论教训

1. **独立A/B有效 ≠ 叠加有效**：海外叠加独立+4.8pp，叠加到完整配置-24pp。因子间有交互效应，最终必须跑组合验证。
2. **单一行情调参会过拟合**：130天调出的 gap Sharpe 3.07 在 5 年框架下降到噪声。所有参数必须在跨周期验证。
3. **数据 bug 的代价**：fast path YoY 环比/同比 bug 和 HMM 全量训练 bug 让基线从 +44% 暴跌到 -34%。任何性能优化必须验证数值一致性。
4. **少即是多**：反弹 slots 3→1 Sharpe 单调上升；参数更激进(sweep的S4/S5)全部更差。
5. **回归分析要先看数据**：周期股 31-60 天死亡区间的假设被 A/B 证伪——因为现有规则已经覆盖。
