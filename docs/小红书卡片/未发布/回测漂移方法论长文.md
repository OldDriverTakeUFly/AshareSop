**标题**:同一个策略,回测收益为什么会自己漂移🔬

**tags**:#量化 #回测 #方法论 #数据分析

**正文**:

先讲一件我们亲历的怪事。八月中旬跑一次五年回测,收益是正的一百二十六;九月初,
同一份代码、同一个票池、同一个参数,重跑一遍,变成了正的四十四。中间没人改过任何
东西——变的只是「日期」。

差额去哪了?我们做了对照实验:九月初再跑一次完全相同的口径,唯一区别是数据的
「版本」。结果:纯数据演化一项,就吃掉了八十一个百分点,比总位移还大。后来又抓到
第三个证人:一次复测里,十天之内同一个回测自己涨了五个点,而这十天里策略行为零变化。

机制其实不玄学,拆开是四层传导。第一层,数据缓存一直在变:财务数据在回补、修正,
估值指标在按周期刷新,你「今天跑的回测」和「上个月跑的回测」,底层根本不是同一份
数据。第二层,因子分数是数据的函数——数据挪一点,动量分、景气分就挪一点。第三层,
闸门是分数的函数——分数挪一点,某只票某天就从不放行变成放行。第四层最致命:路径
是闸门的函数——第一天多买了一只票,后面的复利路径就整体分岔,五年下来就是几十个
点的差距。每层都只放大,不收敛。

所以我们查成交明细,发现两份回测的第一笔交易都不一样:一份三月才开出第一笔仓位,另一份
开年第一天就买了。一个原子的分歧,滚成了一条河。

这件事对普通投资者意味着什么?三条。其一,任何回测平台的漂亮数字,都是「某个
数据快照上的数字」,快照过期,数字过期;看到「历史收益多少」先问一句数据是哪天的。
其二,两份回测要比较,必须同一天、同一数据源各跑一次——跨月比较基本是在比数据
版本,不是在比策略。其三,「我上个月明明跑出来是另一个数」大概率不是你记错,是
数字真的动了。

我们的对策是把它变成仪表:每周固定一个口径(同一个池子、同一段历史、同一份参数)
重跑一次,把数字轨迹记进台账,起名叫漂移哨兵。数字每周挪多少,从此可观测——它
既是回测结论的置信区间,也是数据层出问题的早期警报。

方法论一句话:回测数字没有「真值」,只有「某数据版本上的读数」。会漂移的不是
你的策略,是你脚下的数据地板。
