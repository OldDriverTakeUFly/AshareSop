**标题**:先把判定线写死,再看结果——反事后诸葛五条纪律📏

**tags**:#量化 #回测 #交易纪律 #方法论

**正文**:

量化研究里最贵的成本,不是数据也不是算力,是自欺。跑完实验看着一堆数字,总能
挑出一组讲得通的故事——这个故事事后永远"合理",也永远无法证伪。我们的解法很笨但
有效:判定线预注册。跑之前,把"什么算成功、什么算失败"写成文字存档,跑完之后
机械执行,一条都不许改。

五条纪律,每条都有一段血泪。

第一条,判定线三档制:采纳线、否决线、中间地带,全部数字化。比如"年度倒退超过
五个点即否决"——不是"表现变差就再想想"。有一次,一个变体全期收益明显更好,按总量
该采纳;但预注册的否决线写着"某一年倒退超线即否",而它恰好超了。线顶住了诱惑,
事后看,那一年恰好是它过拟合的铁证。

第二条,烟测只验机制,不验方向。短窗口冒烟测试能告诉你"代码跑通了、机制触发了",
永远不能告诉你"方向对不对"——我们有一个实验,冒烟窗口与全期的结果方向完全一致,
看起来稳;另一个实验冒烟是负的,全期也是负的。两个例子教会同一件事:方向判断
必须留给全期,烟测只配回答"通不通"。

第三条,负结果照写归档。被否决的实验和被采纳的一样入库,写清为什么败——这不是
仪式感,数据库里那些"此路不通"的记录,后来至少三次帮我们挡住了重复踩坑。

第四条,单一变量。每次只改一个机制,组合拳单独验证——我们试过把两个单项都加分
的改动合在一起,总成绩反而崩了,原因是两项在同一时段抢同一段收益。

第五条,跨期数字同日重锚。这个系列第一篇讲过数据漂移:两份结果要比较,必须同
一天、同一数据各跑一遍,否则比的是数据版本,不是策略。

这套纪律的核心只有一句话:把"判断"前置到看数据之前。写判定线的时候你是科学家,
看完成绩单再下结论的时候,你只是个讲故事的人。
