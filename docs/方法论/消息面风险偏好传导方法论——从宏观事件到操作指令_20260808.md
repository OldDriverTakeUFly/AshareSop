## 一、为什么需要这套方法论

### 1.1 痛点

传统的选股框架（davis_analyzer）是**基本面驱动的**——估值分位、景气度、困境反转。但 2026 年 7-8 月的实战表明：

- 7/17 创业板暴跌 -7.14% 不是基本面恶化，是"AI 算力过剩"叙事崩塌
- 8/7 黄金+科技齐涨不是估值修复，是"非农转负→降息预期"驱动
- **同一天、同样的股票，因为不同的消息面，走出了完全相反的方向**

如果只看基本面（davis 打分），无法解释也无法应对这些波动。需要一个**独立的"消息面→风险偏好"分析层**，和基本面选股层互补。

### 1.2 基本面 vs 消息面的分工

| 层次 | 回答什么问题 | 时间尺度 | 我们的工具 |
|------|------------|:--------:|----------|
| **基本面层** | 买什么？（标的筛选） | 周/月 | davis_analyzer pipeline |
| **消息面层** | 什么时候买/卖？（择时+风控） | 日/周 | **本方法论 + international_overlay** |
| **执行层** | 怎么买/卖多少？（仓位+止损） | 日 | paper_trading strategy |

消息面层是基本面和执行之间的**翻译器**——把宏观事件翻译成对当前持仓和候选的操作指令。

## 二、核心理论：风险偏好传导链

### 2.1 一切消息面通过"风险偏好"定价

任何宏观事件（非农、加息、地缘、政策）都不直接决定股价，它通过改变市场的**风险偏好（Risk Appetite）**来重新定价所有资产：

```
宏观事件 → 市场对未来的预期改变
    → 风险偏好升降（想不想承担风险）
        → 资金在"风险资产"和"避险资产"之间重新配置
            → 各类资产价格变动
```

### 2.2 风险偏好的两态模型

为了可操作，把连续的风险偏好简化为**两态+过渡**：

| 状态 | 特征 | 资产表现 | 对应操作 |
|------|------|---------|---------|
| **Risk-On（追逐风险）** | 乐观、流动性充裕、降息预期 | 🟢 科技股涨 + 黄金涨 + 美元弱 | 加仓成长，bull regime |
| **Risk-Off（逃离风险）** | 恐慌、流动性紧缩、加息/衰退 | 🔴 科技股跌 + 美元强 + 黄金先跌后涨 | 降仓防守，bear regime |
| **过渡（分歧）** | 混合信号、观望 | 资产相关性打乱 | 中性，neutral regime |

### 2.3 关键洞察：黄金是"终极翻译官"

黄金在两种状态下都可能涨，但**驱动逻辑完全不同**：

| 场景 | 黄金驱动 | 股市 | 黄金 vs 股市 |
|------|---------|:----:|:----------:|
| Risk-On（降息预期） | 美元弱+实际利率降 | 涨 | **同涨** ✅ |
| Risk-Off（恐慌） | 避险+信用担忧 | 跌 | **背离** ⚠️ |

**当黄金和股市同涨 → 通常是 Risk-On（健康）**
**当黄金涨股市跌 → 通常是 Risk-Off（危险）**

这是判断市场状态最简洁的单指标信号。

### 2.4 "坏数据=好消息"悖论与临界点

金融市场的反直觉现象：坏经济数据反而推涨股市。逻辑是"坏数据→降息→估值扩张"。但这有一个**临界点**：

```
温和走弱（非农 -2.3万、失业 4.1%）
    → "坏数据=好消息"（庆祝降息）→ 股市涨 ✅
        ↓ 继续恶化
硬衰退（非农 -10万+、失业 >5%、消费萎缩）
    → "坏数据=坏消息"（恐慌衰退）→ 股市跌 🔴
```

**区分"温和走弱"和"硬衰退"的关键指标**：
- 失业率破 5% → 逼近临界
- 初次申请失业金 >30 万 → 硬衰退信号
- 消费支出连续两月负增长 → 确认衰退

## 三、四维消息面分类与传导路径

### 维度 ①：美联储政策与美国数据（全球风险偏好锚）

**核心事件**：FOMC 议息、非农、CPI、PMI、GDP、PCE

**传导路径**：
```
非农/CPI → 美联储加息/降息预期
    → 美债收益率（利率锚）
        → 美元强弱
            → ① 美股估值（折现率）→ 科技股敏感
            → ② 新兴市场资金流 → A股北向资金
            → ③ 黄金（美元计价+实际利率）
```

**信号矩阵**：

| 数据方向 | 市场预期 | 美债 | 美元 | 美股 | 黄金 | A股 |
|---------|---------|:----:|:----:|:----:|:----:|:---:|
| 数据弱（非农转负/CPI低） | 降息预期↑ | ↓ | ↓ | ↑(短期) | ↑ | ↑(外资回流) |
| 数据强（非农大增/CPI高） | 加息预期↑ | ↑ | ↑ | ↓ | ↓ | ↓(外资流出) |
| 数据极弱（硬衰退信号） | 衰退恐慌 | ↓↓ | 先↑后↓ | ↓↓ | ↑↑ | ↓↓ |

**关键阈值**（2026 年语境）：
- 非农 >+15万：强劲，加息预期升温
- 非农 0~+10万：温和，按兵不动
- 非农 <0：转负，降息预期主导 ← **当前（8月）**
- 失业率 >5%：硬衰退警戒

### 维度 ②：地缘+汇率+套息（突发事件驱动器）

**核心事件**：中东冲突（油价）、日元极端（套息平仓）、中美关系（科技脱钩）

**传导路径**：
```
地缘冲突 → 油价飙升（供给冲击）
    → 通胀预期↑ → 加息压力 → 股市杀估值
        → 同时避险需求 → 黄金涨（与股市背离）

日元极端（USD/JPY >160）
    → 套息交易脆弱 → 随时可能平仓
        → 全球流动性收缩 → 所有风险资产跌（含黄金）
```

**信号矩阵**：

| 事件 | 性质 | 股市 | 黄金 | 美元 | 油价 | A股影响 |
|------|------|:----:|:----:|:----:|:----:|---------|
| 中东冲突升级 | 供给冲击 | ↓ | ↑ | ↑ | ↑↑ | 资源股短期涨，科技股跌 |
| 日元套息平仓 | 流动性冲击 | ↓↓ | ↓(先) | ↑ | — | 全市场系统性回调 |
| 中美科技脱钩 | 结构性 | 科技↓ | — | — | — | 半导体国产替代反而利好 |

**关键阈值**：
- USD/JPY >160：套息脆弱区（我们的 overlay 已覆盖）
- 布伦特 >$95：通胀压力临界
- VIX >30：恐慌模式

### 维度 ③：国内政策与行业（A 股板块直接驱动）

**核心事件**：降准降息、财政刺激、行业政策（半导体/新能源/房地产）、社融/PMI

**传导路径**：
```
国内宽松（降准/降息）
    → 流动性充裕 → 估值中枢抬升 → 全市场涨（尤其成长股）

行业政策（如半导体扶持/新能源补贴）
    → 特定行业景气度↑ → 该板块相对超额

经济数据弱（PMI<50/社融萎缩）
    → 政策宽松预期↑ → 反而可能涨（政策博弈）
```

**信号矩阵**：

| 政策方向 | 流动性 | 市场反应 | 受益板块 |
|---------|:------:|---------|---------|
| 降准降息 | ↑↑ | 全市场涨 | 成长股 > 价值股 |
| 财政刺激 | ↑ | 基建/消费涨 | 建材/消费 |
| 行业扶持 | — | 结构性 | 政策指向行业 |
| 监管收紧 | ↓ | 结构性跌 | 被监管行业 |

### 维度 ④：商品与行业供需（资源/周期股驱动）

**核心事件**：金价/铜价/油价/锂价、存储芯片价格、面板价格、产能利用率

**传导路径**：
```
商品涨价 → 资源/周期股盈利↑
    → 但要区分: 需求驱动(可持续) vs 供给驱动(脉冲)

存储芯片涨价 → 半导体景气度↑ → 相关标的估值切换
```

**关键判断**：商品涨价是**需求驱动**还是**供给驱动**？
- 需求驱动（经济扩张拉动）：可持续，股票趋势性上涨
- 供给驱动（减产/地缘）：脉冲式，涨完会回落

## 五、操作指令映射：风险偏好→仓位/选股/风控

### 5.1 从风险偏好到操作的三层映射

| 风险偏好状态 | regime | 仓位策略 | 选股偏向 | 风控策略 |
|:----------:|:------:|:--------:|:--------:|:--------:|
| **Risk-On** | bull | 70-100% | 成长/科技/资源 | 正常止损 |
| **过渡** | neutral | 30-50% | 低估值+高景气 | 收紧止损 |
| **Risk-Off** | bear | 0-30% | 防御(消费/医药/公用) | 绝对止损 |

### 5.2 消息面事件→操作指令速查表

| 事件 | 叠加信号 | 操作指令 |
|------|---------|---------|
| 非农转负 + 美债跌 | 降息预期↑ | **加仓半导体/科技（估值修复）**；黄金股不追高（已贵） |
| CPI 超预期 + 油价涨 | 加息预期↑ | **降仓科技**；资源股短期受益但警惕脉冲 |
| 中东冲突 + 油价飙 | 供给冲击 | **减仓科技**；能源股短期多；黄金避险涨 |
| 日元 >160 + VIX 升 | 套息风险 | **全面降仓**；现金为王 |
| 美联储确认降息 | Risk-On | **加仓成长**；A 股外资回流利好 |
| 国内降准降息 | 流动性宽松 | **加仓 A 股**；成长 > 价值 |
| 半导体扶持政策 | 行业利好 | **加仓国产半导体** |

### 5.3 消息面与基本面冲突时的优先级

当消息面和基本面冲突时（比如基本面好但消息面 Risk-Off），用**优先级规则**：

1. **系统性危机信号（日元套息平仓/VIX>40）→ 最高优先级**，无视基本面，立即降仓
2. **趋势性政策转向（降息周期启动）→ 高优先级**，调整 regime，影响仓位上限
3. **一次性事件脉冲（地缘冲突）→ 中优先级**，短期影响，不改变基本面选股
4. **噪音（单日波动）→ 忽略**

### 5.4 传导效率矩阵（2026-08-13 预测复盘新增）

不同资产对同一个宏观事件的反应效率**严重不对称**——不能把"美股Risk-On"等同于"A股Risk-On"。以下是经验传导效率矩阵：

| 宏观事件 | 对美股 | 对A股 | 对黄金 | 传导效率说明 |
|---------|:------:|:-----:|:------:|------------|
| 美联储降息预期↑ | ✅ 直接有效 | ⚠️ 间接衰减 | ✅ 直接 | 美股：折现率→估值；A股：需经美元→汇率→外资→A股四步链 |
| 美联储加息预期↑ | ✅ 直接杀估值 | ⚠️ 间接 | ✅ 跌 | 同上，A股传导弱 |
| BOJ加息/日元升值 | ⚠️ 套息平仓→美股跌 | ⚠️ 双向（见下文） | — | A股是间接传导+人民币升值对冲 |
| 非农/CPI 数据 | ✅ 即时反应 | ⚠️ 次日衰减 | ✅ 即时 | 数据对美股当日有效，A股次日影响已大减 |
| 地缘冲突 | ⚠️ 短期恐慌 | ⚠️ 情绪传导 | ✅ 避险涨 | A股主要受情绪影响，无基本面传导 |
| 国内政策（降准降息） | ❌ 无直接影响 | ✅ **直接有效** | — | A股由国内政策直接驱动，这才是主因 |

**核心教训（2026-08-13 复盘）**：预测"美联储降息预期→A股上涨"失败（上证横盘-0.33%），因为高估了美联储→A股的传导效率。**A股走势由国内因素主导**，美联储政策只是边际影响。

**操作含义**：
- 美联储事件（非农/FOMC/CPI）→ 主要影响 overlay 风险分和美股信号，**不直接预测A股涨跌**
- 国内事件（降准降息/PMI/社融）→ **才是A股的主驱动**，应给更高权重
- overlay 的设计是对的——它不预测A股涨跌，只判断"国际环境是否危险"（降级 bull→neutral）

## 六、接入 international_overlay

### 6.1 当前 overlay 的局限

我们的 `international_overlay.py` 已经用 4 个信号算海外风险分（美债/VIX/日元/美股）。但它是**被动反映**——从 daily_basic 读已有数据。它不会**主动预判**即将到来的事件（如 FOMC 日、非农日）。

### 6.2 升级方案：事件日历 + 预期偏差驱动

在现有 4 个实时信号之外，增加一个**"事件预期偏差"信号**：

```python
# 伪代码：接入 international_overlay 的第5个分信号
def _score_event_surprise(trade_date: str) -> SubSignal:
    """重大宏观数据发布日的预期偏差 → 风险分。

    在非农/CPI/FOMC 发布日，比较实际值 vs 预期值：
    - 数据远弱于预期（非农转负）→ 降息预期↑ → 风险偏好↑ → 风险分降
    - 数据远强于预期 → 加息预期↑ → 风险偏好↓ → 风险分升
    """
    event = load_economic_calendar(trade_date)
    if event is None:
        return SubSignal("event", 0.0, None, "无重大事件")

    actual, expected = event.actual, event.expected
    surprise = actual - expected

    if event.type == "nonfarm":
        if surprise < -50_000:   # 远弱于预期
            return SubSignal("event", 0.0, surprise, "非农远弱→降息预期→风险偏好↑")
        elif surprise > +50_000: # 远强于预期
            return SubSignal("event", 80.0, surprise, "非农远强→加息预期→风险偏好↓")
    # ... CPI/FOMC 类似

    return SubSignal("event", 30.0, surprise, "数据中性")
```

### 6.3 经济日历数据源

需要一个**宏观经济日历**作为数据源。选项：
- **Tushare `us_tycr`** 已有美债，但没有非农/CPI 预期值
- **AKShare** 有 `macro_china_*` 和 `economic_calendar` 接口
- **手维护**：每周 FOMC/非农/CPI 日历固定（每月第一个周五非农等），可半自动

**推荐方案**：用 AKShare 的 `economic_calendar` 获取事件日历 + 预期值，在 `overseas_market_data.py` 里增加一个"经济日历"采集模块，和美债/汇率并行。

### 6.4 接入后的完整 overlay 架构

```
international_overlay 风险分 = 加权平均(
    ① 美债10Y变化      25%  (实时,已有)
    ② US-VIX水平       20%  (实时,已有)
    ③ USD/JPY极端度    20%  (实时,已有)
    ④ 美股隔夜涨跌      15%  (实时,已有)
    ⑤ 事件预期偏差      20%  (新增,事件日才触发)
)
```

事件信号的特点是**稀疏但猛烈**——平时为 0（无事件），一旦触发影响极大（权重 20% 足以翻转整体风险等级）。这和前 4 个实时信号互补。

## 七、案例复盘：2026 年 7-8 月四次事件验证

用本方法论复盘四次真实事件，验证传导链的准确性：

### 案例 1：7/17 创业板暴跌（AI 算力过剩叙事崩塌）

| 维度 | 分析 |
|------|------|
| 事件性质 | 维度②（地缘+叙事），Meta 卖算力 + 英伟达循环融资质疑 |
| 传导链 | AI 叙事崩塌 → 科技股杀估值 → 创业板 -7.14% |
| 我们的系统反应 | overlay 风险分 41.5（中等），未达降级阈值 |
| 操作指令（事后） | 应降仓半导体（Top50 里 11 只），但 overlay 太保守 |
| 教训 | **叙事类事件**比数据类事件更难量化，需增加"板块情绪"信号 |

### 案例 2：7/29-30 美联储+日央行双会（无黑天鹅）

| 维度 | 分析 |
|------|------|
| 事件性质 | 维度①（美联储政策），市场预期按兵不动，结果符合 |
| 传导链 | 符合预期 → 不确定性消除 → 日元回落 → 风险偏好修复 |
| 我们的系统反应 | overlay 风险分从 41.5 降至 10.7 |
| 操作指令 | bull 不降级，正常仓位 ✓ |

### 案例 3：8/7 非农转负（降息预期飙升）

| 维度 | 分析 |
|------|------|
| 事件性质 | 维度①（美联储+美国数据），非农 -2.3万，远弱于 +8万 预期 |
| 传导链 | 非农转负 → 降息预期↑ → 美债跌/美元弱/黄金涨/科技涨 |
| overlay 当前反应 | 未覆盖（economic_calendar 未接入） |
| 操作指令（应执行） | Risk-On，加仓科技+不追黄金股 |
| 升级后反应 | 事件信号触发（偏差 -10万），风险分降低 → bull 不降级 |

### 案例 4：8/5 小非农 ADP 爆冷（黄金单日 +4%）

| 维度 | 分析 |
|------|------|
| 事件性质 | 维度①，ADP 就业弱于预期，是非农的预演 |
| 传导链 | ADP 弱 → 非农转负预期 → 黄金提前涨 188 美元（+4%） |
| 教训 | **事件有预演**——前瞻指标（ADP/初请失业金）需纳入监控 |

## 八、局限性与认知陷阱

### 8.1 消息面分析的三个陷阱

| 陷阱 | 表现 | 解药 |
|------|------|------|
| **过度反应** | 把噪音当趋势，频繁调仓 | 只对"系统性信号"（维度②+①的趋势性转向）反应 |
| **后视偏差** | 事后看传导链清晰，事前无法判断 | 用预判+确认两步法，不 all-in 单一情景 |
| **线性外推** | "降息=永远涨" | 设定临界点（失业率>5%转为衰退逻辑） |

### 8.2 方法的边界

消息面方法论**不能预测**：
- 具体涨跌幅度（只能定方向）
- 市场反应的时滞（有时即时，有时延迟数日）
- "黑天鹅"事件本身（无法预判，只能应对）

消息面方法论**能做**的：
- 判断当前的风险偏好状态（Risk-On/Off）
- 把宏观事件翻译成操作指令（加仓/减仓/中性）
- 设定自动化的风控响应（overlay 降级）

### 8.3 和基本面的关系

**消息面是"择时层"，基本面是"选股层"。** 两者不可互替：

- 只看基本面：选对了股票但买在了错误的时间（7/17 暴跌前满仓半导体）
- 只看消息面：踩对了节奏但买错了股票（追高黄金股）
- **两者结合**：消息面定仓位+择时，基本面定标的——这是本方法论的最终目标
