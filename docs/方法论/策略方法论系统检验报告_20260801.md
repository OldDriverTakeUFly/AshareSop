## 一、策略架构总览（当前状态）

### 复合评分公式

```
composite = 动量 × 0.40 × legacy_weight
          + best_secondary × 0.40 × legacy_weight
          + 景气 × 0.20 × legacy_weight
          + 量价 × 0.05
          + 质量 × 0.10
          + 缺口 × 0.05
```

其中 `legacy_weight = 1.0 - (0.05 + 0.10 + 0.05) = 0.80`，所以实际权重：

| 维度 | 实际权重 | 来源 |
|------|---------|------|
| 动量 | 32% | daily_price 20/60/120 日动量 |
| 次维度（取最大值） | 32% | 筹码集中度 / 红利 / 前瞻 / 景气 |
| 景气 | 16% | G+ΔG 增长加速模型 |
| 质量 (QMJ) | 10% | ROE + OCF/NI + 杠杆安全 |
| 量价 | 5% | 平台突破 / 低位放量 |
| 缺口 | 5% | 开盘跳空 |

### 7 层买入过滤

1. 动量 ≥ 65
2. 板块趋势 ≠ down（20d 收益 + MA 对齐双确认）
3. 至少 1 个次维度达标
4. 短期动量（5d return > 0）
5. PE 百分位 < 80%（量价确认可豁免）
6. 日内振幅 ≤ 8%
7. 市场环境（熊市不开仓）

### 风险管理层

| 规则 | 触发条件 | 参数 |
|------|---------|------|
| 硬止损 | 亏损 ≥ 7-12%（市场×板块查表） | risk_stop_mult=0.70 |
| 止盈 | 盈利 ≥ 10-30%（市场×板块查表） | — |

## 二、方法论缺陷分级

### 🔴 严重（系统性高估回测收益）

#### 缺陷 1：Universe 前视偏差（look-ahead in stock selection）

**现状**：所有 A/B 测试用 2025-12-31 截面的 90 天动量排名选 top-200 股票，然后从 2026-01-05 开始回测。

```python
# gap_abx.py / freq1_test.py 的 universe 构建
ORDER BY (a.close / b.close - 1) DESC LIMIT 200
# a = 2025-12-31 收盘价, b = 2025-10-01 收盘价
# → 选的是过去 90 天涨得最多的 200 只
```

**问题**：回测起点（01-05）选的是 Q4 涨幅最大的股票。这些股票自带动量惯性，在 1-2 月继续上涨的概率本身就高于平均。**策略的 "+13.94% 基准收益" 里有一部分是 universe 选择带来的，不是 alpha**。

**影响程度**：中等。动量效应在 A 股确实存在（3-6 个月动量），但用「已知涨起来的股票」做回测起点会放大收益。

**修复方案**：
- 短期：在回测里用 **walk-forward universe**（每月初动态重选，而非固定全期）
- 长期：5 年回测用 2021-01-04 截面构建（已实施，用成交额排名而非动量，更保守）

---

#### 缺陷 2：财务数据前视偏差（已修复，但历史 A/B 受影响）

**现状**：`fetch_financial_data(client, code, periods=12)` 之前漏传 `as_of` 参数，用 `date.today()` 做窗口终点。

**后果**：
- 回测 2026-01-05 时，用了 2026-07-31 才披露的 Q2 财报计算景气度/质量分
- 这让质量因子（qw=0.10）和景气度评分在历史回测里"看到了未来"

**影响程度**：中等。质量因子是最新突破（Sharpe +2.197），其 A/B 结果可能有前视偏差水分。但 gap/freq A/B 是在同一偏差下对比，相对结论（哪个参数更好）依然有效。

**修复状态**：✅ 已修复（`as_of=as_of`）。5 年回测会用正确的 point-in-time 数据。

---

#### 缺陷 3：HMM 前视偏差

**现状**：HMM 用 2021-01-01 到 `end_date` 的全部指数收益训练，然后 predict 历史状态。

```python
# market_regime.py
df = _load_index_returns("000001.SH", "20210101", end_date)  # 包含未来数据
model.fit(returns)
predictions = model.predict(returns)  # 用未来训练的模型看历史
```

**问题**：回测 2021-06-01 时，HMM 模型是用 2021-01 到 2026-07 的数据训练的。状态分类（bull/bear/neutral）用了未来信息。

**影响程度**：较小。HMM 主要识别大趋势（均值/方差分布），全样本训练的参数比 walk-forward 更稳定，对状态边界附近的预测影响有限。但这是理论上的，实际影响需要 walk-forward A/B 验证。

**修复方案**：理论上应该用 expanding window（每天只用截止当日的数据重训），但计算量爆炸（1300 次训练）。当前「全样本训练 + 诚实标注」是合理的工程妥协。

---

### 🟡 中等（影响结论可靠性）

#### 缺陷 4：单一行情样本 + 过拟合

**现状**：所有 A/B 测试（amplitude/quality/gap/freq 共 ~15 个参数）都在 **2026-01-05 → 07-21（130 天）** 这一段行情里调参。

**问题**：
- 这 130 天是单一行情（2026 上半年的某段趋势）
- 调了 15+ 个参数，每参数约 8-10 个交易日的"证据"
- 经典过拟合：参数数量 × 取值空间 远超 样本能约束的自由度
- **gap_weight=0.05 的 Sharpe 3.07 几乎必然有水分** —— 它在 130 天里恰好表现好

**影响程度**：高。这是最需要警惕的风险。即使没有前视偏差，单一行情调参也会让参数过拟合。

**修复方案**：
- 即将运行的 5 年回测（2021-2026）会提供样本外验证
- 如果某参数在 2021-2022（熊市）和 2023-2024（震荡市）都有效，才能确认是真 alpha
- 建议后续采用 **train/test 分割**：2021-2023 调参，2024-2026 验证

---

#### 缺陷 5：Sharpe 比率定义不严谨

**现状**：所有 A/B 测试报告里的 "Sharpe" 实际是 `return_pct / max_drawdown_pct`（Calmar ratio）。

```python
sharpe = ret / mdd if mdd > 0.01 else 0   # 这是 Calmar，不是 Sharpe
```

**问题**：
- Calmar 只看最终收益和最大回撤，忽略波动路径
- 真 Sharpe = mean(daily_returns) / std(daily_returns) × sqrt(252)
- 同一个 Calmar 可能对应完全不同的波动路径（平稳增长 vs 大起大落）

**影响程度**：中。相对比较（A vs B）依然有效，但绝对数值（"Sharpe 3.07"）会误导。

**修复方案**：回测脚本里加真 Sharpe 计算（已有 daily_return 数据，只需加聚合统计）。

---

#### 缺陷 6：事件因子反向（已诚实记录，但值得反思）

**现状**：事件因子（减持/解禁）在全市场实证里 CAR 显著，但集成到策略后**反向**（V3 < V2 by 3.92pp）。

**根本原因**：实证用的是全市场样本，策略用的是「强势股 universe」。强势股的"正常减持" ≠ 基本面恶化，股价经常继续涨。

**教训**：**因子有效 ≠ 集成有效**。子样本行为可能与全样本相反。这是量化研究里最经典的陷阱之一。

**状态**：✅ 已诚实关闭（`enable_event_filter=False`）。但这个教训应该推广到所有因子 —— 每个因子都应该在目标 universe 里做子样本验证，而非只看全市场 IC。

---

### 🟢 轻微（已处理或影响有限）

#### 缺陷 7：Universe 固定不轮换

**现状**：回测期间 universe 固定为初始选的 200 只，不随时间调整。

**问题**：某些股票可能在回测期间退市/ST/停牌，但仍留在 universe 里。

**影响程度**：低。实际执行时有价格检查（停牌股会被跳过）。

---

#### 缺陷 8：交易成本未建模

**现状**：回测未扣除手续费/印花税/滑点。

**影响程度**：中低。A 股双边成本约 0.15%（佣金 0.025%×2 + 印花税 0.05% + 滑点 ~0.05%）。130 天 ~170 笔交易 × 0.15% ≈ 0.25%/年，对高频策略影响更大。

**修复方案**：在回测里加 `commission_rate=0.0008, slippage=0.0005` 参数。

## 三、方法论优点（值得保留）

### ✅ 1. 渐进式因子验证 + A/B 测试文化
每个因子都经过「实证研究 → IC/分组验证 → A/B 回测 → 决策」的完整流程，失败案例（事件因子、自适应卖出、动态权重、Amihud、龙虎榜、回购）都诚实记录。

### ✅ 2. 趋势跟踪哲学的一致性
策略坚持「不追单日反弹，等确定性趋势」（如 07-21 半导体涨停日正确地没有追入）。板块趋势用双确认（20d 收益 + MA 对齐），避免假突破。

### ✅ 3. 分层风控设计
市场层（HMM 仓位门控）→ 板块层（趋势过滤）→ 个股层（止损/止盈/动量崩塌）→ 量价层（高位放量）。四层独立运作，单点失效不会击穿整体。

### ✅ 4. 集中持仓 + 紧止损的 Sharpe 扫描确认
12 组合扫描证明 pos=5 + stop=0.70 最优，符合「集中火力 + 快速止损」的趋势跟踪原则。

### ✅ 5. 因子失效的诚实记录
事件因子反向、软门槛更差、自适应卖出/动态权重/HMM 多指数 全部失败 —— 这些负案例的记录比成功案例更有价值。

## 五、关键诚实性声明

> 以下结论需要带「置信度」看待：

1. **"生产配置 Sharpe +2.197/+3.073"** —— 这些数值**被多个偏差系统性高估**：
   - Universe 前视偏差（选了已涨股）
   - 财务前视偏差（已修复，但历史 A/B 受影响）
   - 单一行情过拟合（130 天调 15 参数）
   - Calmar 而非真 Sharpe

2. **"gap_weight=0.05 是重大突破"** —— 相对结论（0.05 > 0.00）可信，但绝对提升幅度（+22.87pp）大概率缩水。5 年回测会给出真实数字。

3. **"策略优于买入持有"** —— **尚未验证**。需要对比基准（沪深300 同期收益）。

4. **策略框架本身是健全的** —— 趋势跟踪 + 多因子确认 + 分层风控的设计合理。问题出在回测验证的严谨性，而非策略逻辑。
