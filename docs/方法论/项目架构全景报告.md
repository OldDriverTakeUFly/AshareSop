## 一、三包依赖关系

```
                    ┌─────────────────────────┐
                    │      davis_webui        │
                    │  FastAPI + Next.js 前端   │
                    │  仅写 tasks/*.json       │
                    └───────────┬─────────────┘
                                │ 单向依赖 davis_analyzer
                                │ (pipeline / sector_pipeline /
                                │  report_generator / rescorer /
                                │  trend / valuation / types)
                                │ ✗ 不依赖 stockhot，不读 SQLite
                                ▼
    ┌───────────────────────────────────────────────────┐
    │              davis_analyzer                        │
    │  量化基本面流水线 + paper_trading + studies/        │
    │                                                   │
    │  ← 依赖 stockhot（数据层 + 少量算法）               │
    │    • market_db / repository (market_data.db)      │
    │    • technical_analyzer (composite_technical_score)│
    │    • tushare_client_safe / tushare_config          │
    │    • volatility.analyzer / index_technical.*       │
    └──────────────────┬────────────────────────────────┘
                       │ 双向依赖
                       ▼
    ┌───────────────────────────────────────────────────┐
    │                   stockhot                         │
    │  数据采集 + 盘面分析 + 通知 + invest_sop            │
    │                                                   │
    │  ← 反向依赖 davis_analyzer（少数路径，懒 import）   │
    │    • advisor → pipeline.run_screening_pipeline     │
    │    • invest_sop → TushareClient / strategy_signal  │
    └───────────────────────────────────────────────────┘
```

### 关键事实

| 关系 | 类型 | 耦合点 |
|------|------|--------|
| davis_webui → davis_analyzer | 单向强依赖 | pipeline / types / report_generator |
| davis_webui → stockhot | **无** | davis_webui 不读 SQLite，不 import stockhot |
| davis_analyzer → stockhot | 硬依赖（模块级） | `tushare_client.py:33` 顶层 import market_db |
| stockhot → davis_analyzer | 懒依赖（函数级） | advisor / invest_sop 内部 `from davis_analyzer...` |

> **部署约束**：davis_analyzer 和 stockhot 必须共存，不能单独运行。

## 三、模块清单

| 层 | 模块 | 核心职责 |

| | `profitability.py` | 盈利质量 |
| | `trend.py` | 估值趋势 |

## 四、数据流全景

```
[盘后 17:00 cron]
  run_daily_scan.py
    ├─ Wave 0: daily_price + daily_basic → market_data.db
    ├─ Wave 1: limit_up → stockhot.db(JSON)
    ├─ Wave 2: fund_flow / dragon_tiger / volatility (并行)
    │           → stockhot.db(JSON) + market_data.db(ivix/volatility)
    ├─ Wave 3: risk_alert (读 Wave 1/2)
    └─ Wave 4: migrate_panels → market_data.db 结构化

[离线回填]
  davis_analyzer/scripts/
    ├─ recompute_tech_factor_5yr.py → tech_factor
    ├─ backfill_intraday_feature_5yr.py → intraday_feature
    ├─ backfill_top_list.py → top_list
    └─ backfill_daily_basic.py → daily_basic

[用户触发]
  davis_webui → POST /api/screening/start
    → tasks._run_pipeline
        → davis_analyzer.pipeline.run_screening_pipeline
            → TushareClient(共享 market_data.db)
            → 8 因子打分 → PipelineResult
        → 序列化 → tasks/{task_id}.json

[实时/盘中]
  paper_trading/executor → 读 daily_price/dragon_tiger/corp_event/
                           tech_factor/intraday_feature/ivix_history
  invest_sop/run_panic_alert → 读 daily_volatility → 飞书推送
```

## 五、已知问题与技术债

### 🔴 严重（影响数据一致性）

| # | 问题 | 现状 | 影响 |
|---|------|------|------|
| 1 | **研究脚本绕过规范数据层** | studies/ 下 13 脚本无一用 TushareClient | 数据获取碎片化、无限流无缓存 |
| 2 | **两套 Tushare 客户端** | TushareClient(400/min) vs safe_tushare_call(5/s) | 限流/重试逻辑重复实现 |
| 3 | **pickle 数据湖** | cache_daily/ + cache_msg/ 非标准缓存 | 同一数据多副本，互不复用 |

### 🟡 中等（影响可维护性）

| # | 问题 | 现状 |
|---|------|------|
| 4 | ~~top_list schema 不在单点维护~~ | ✅ 已修复（2026-08-02 纳入 market_db.py） |
| 5 | corp_event 写入方不在标准路径 | executor 读它但主代码无写入方 |
| 6 | yoy 计算可信度 | financial_fetcher 的累计数据处理被研究脚本绕过 |
| 7 | 双库并存 | stockhot.db(JSON) + market_data.db(结构化) 双写 |

### 🟢 低（功能缺失但不阻塞）

| # | 问题 | 现状 |
|---|------|------|
| 8 | 港股数据零沉淀 | AKShare 仅临时脚本用，未封装 |
| 9 | scheduler 已废弃 | 代码仍在，被 cron + run_daily_scan 取代 |
| 10 | 双 FastAPI | davis_webui(8322) vs stockhot/api 各跑各的 |
