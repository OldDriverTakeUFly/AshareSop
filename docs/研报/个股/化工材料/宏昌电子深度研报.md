### 2.4 技术代际演进与技术发展方向

- **当前代际**：环氧树脂体系处于"通用 FR-4 环氧（成熟）→ 高频高速特种环氧/低氯环氧（爬坡）"的代际切换点。高频高速树脂技术平台上，GA-686N 满足 AMD 平台 A4 等级需求并进入 AMD 终端材料库；GA-886/GA-686/GA-886N 进入 Intel 高速材料库；GA-686N/GA-688N 参与 Intel 测试项目（2026 半年报，界面新闻 2026-08-25）。
- **演进路径**：通用环氧 → MDI/酚醛改性/特种环氧（对应 M4 以下及无卤无铅 FR-4）→ 高频高速复配体系（低 Df 环氧与碳氢/PPO 复配）→ 半导体级膜材（GBF 增层膜 G10→G11 研发中）。
- **M10 树脂环节中环氧的"配角"定位（诚实分析）**：英伟达 M8 以 PPO 为主/碳氢为辅（约 2:1），M9/M10 转为碳氢为主、PPO 为辅并掺 BCB（东方财富财富号 M10 基材梳理 2026-08-12）；碳氢体系复配中会引入 MPPO、BMI、CE，甚至**高纯低氯环氧**以改善耐热与加工性（国信证券研报）；圣泉集团投关记录（2025-12-03）亦确认 M9/M10 体系中 PPO/碳氢为主。**结论：高端 AI 覆铜板的树脂主角是碳氢与 PPO，环氧只是改性配角——宏昌的环氧主业并不直接等比例受益于 M10 放量，其弹性来自特种环氧复配渗透 + 自有高速覆铜板 + 增层膜三条间接路径。市场若按"M10 树脂供应商"直接线性外推，属于叙事放大。**
- **GBF 增层膜说法核实**：与晶化科技 2023 年起合作，产品用于 FCBGA/FCCSP 封装；GBF C+ G10 低介电损耗、可用于 1.6T 以上光模块与 AI 服务器主板，已获下游板厂认证、涂布产线建设中；G11 在研发。配套"半导体级功能性树脂膜材项目"计划投资约 6000 万元，ABF 载板增层膜产线规划年产量 172.8 万平方米（2026 半年报，界面新闻 2026-08-25）。**注意**：自媒体流传的"通过台积电认证、2026Q4 规模量产"（雪球/东财号）未见公司公告口径证实，本报告不采信为事实，仅标注为市场传闻。

### 3.2 拐点成因诊断

2025 全年"增收不增利"（营收 +43.5%、净利 -30.1%）到 2026H1 利润反转的驱动：

3. **Q1 利润近零→H1 反转**：单季利润弹性极大，体现大宗树脂成本传导的时滞与新产能折旧前置（估算，基于 Q1/H1 差分：Q2 单季归母约 0.389 亿元，占 H1 的 99%）。

## 第四章：景气度分析——G+ΔG 框架下的周期定位

### 4.1 引擎计算结果（davis_analyzer，2026-08-28）

| 指标 | 数值 |
|---|---|
| 景气度复合分 | 56.2 / 100 |
| ΔG | +10.69 pp |
| 营收分 / 利润分 | 85.91 / 29.75 |
| 斜率分 / 持续分 | 26.11 / 100.0 |
| 阶段判定 | **加速期** |

### 4.2 G 与 ΔG 人工核算

- 营收 G：2025FY +43.5% → 2026H1 +64.8%，**增速上行的 G**（tushare income）；
- 利润 G：2025FY -30.1% → 2026H1 +141.1%，符号由负转正（低基数放大，H1 绝对额仅 0.39 亿）；
- ΔG ≈ +10.7pp（引擎口径，以平滑序列计算），方向与人工核算一致：**加速**。

### 4.3 山峰理论定位

Δg 为正 → **左山坡（上山段）**。营收端确实处于景气回升坡道；但利润的绝对水平（年化不足 1 亿）说明公司只是"山脚起步"，与股价所处的历史估值极高位形成错位。

### 4.4 30% 阈值检验

营收增速 64.8% > 30% 阈值 ✓；利润增速 +141% 名义上远超阈值，但**属低基数效应**（H1 净利仅 0.394 亿，2025 同期 0.163 亿），按 skill 纪律标注"基数效应"，不视为真实 30%+ 盈利动能。

### 4.5 二次点火筛选

首次点火（营收+毛利率双升）已确认；二次点火需验证：①8 万吨功能性环氧产能利用率与毛利率续升；②覆铜板毛利率从 4.42% 修复；③增层膜从认证走向收入。当前仅 ① 部分可证，②③ 待披露——**二次点火未确认**。
