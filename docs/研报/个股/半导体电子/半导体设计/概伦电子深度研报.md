## 第一章：公司概览——伯克利器件建模血脉的"回流者"

### 1.1 创始人与管理层

- **创始人/董事长 刘志宏**：1956 年生，香港大学电子电气工程博士（注：任务书所称"Berkeley PhD"口径不确——公开履历为港大博士 + 1990-1993 年 UC Berkeley 电机工程与计算机科学系博士后，百度百科/华南理工大学页面/概伦官网，中高置信）。在伯克利期间作为**主要开发者创建 BSIM3 V1/V2/V3 半导体器件模型**——BSIM3V3 是被 CMC 采纳、统治 1990s-2000s 产业界的 SPICE 标准模型，至今仍是多数成熟工艺 PDK 的底层语言（概伦官网，高）。曾共同创立 BTA Technology 与 **ProPlus Design Solutions**（概伦前身/关联公司），拥有十多项半导体及 EDA 专利，获 IEDM 最佳论文奖、山东省泰山学者海外特聘专家（公司官网/媒体，中高）。2010 年回国创立概伦电子。
- **管理风格**：典型"技术宗师型"掌舵——公司的产品哲学（把单一环节做到全球领先，而非铺全流程）直接源自创始人在 BSIM 标准制定中的履历。

## 第二章：业务与产品矩阵——器件建模深井 + 新嫁接的 IP 宽口

### 2.1 经营范围

EDA 工具（制造类/设计类）授权、半导体器件特性测试仪器、半导体工程服务；并购后新增半导体 IP 授权与芯片定制服务（法定经营范围+并购公告）。

### 2.2 核心产品矩阵

| 产品线 | 覆盖环节 | 行业地位 |
|--------|---------|---------|
| **BSIMProPlus** | SPICE 器件模型建模平台（电学/物理/版图特性建模，内嵌并行 NanoSpice 仿真器，支持 CMC 标准 + Verilog-A） | 多年保持 SPICE 建模市场与技术领先，被众多头部晶圆厂采用（官网，高） |
| **SDEP** | 智能半导体器件模型自动化提取平台 | **三星代工厂采用**，缩短 SPICE 模型开发时间（公司官方新闻，高） |
| **NanoSpice / NanoDesigner** | 大容量高精度 SPICE 仿真、设计平台 | 仿真细分国产领先（官网，中高） |
| **DTCAD / 器件仿真（TCAD 类）** | 器件级仿真与工艺-器件协同优化 | 与 Silvaco/Synopsys Sentaurus 同场竞技（行业分析，中） |

| **锐成芯微 IP 库**（并购新增） | 模拟/数模混合 IP、存储 IP、射频 IP 授权 + 芯片定制 | 国内头部独立 IP 供应商之一，业绩承诺 2025-27 IP 授权营收 1.21/1.43/1.68 亿（财联社，高） |
| **纳能微**（并购新增 45.64%） | IP 授权 | 业绩承诺 2025-27 IP 授权营收 7361 万/8685 万/1.02 亿（财联社，高） |

### 2.3 分业务收入结构

2025 年（并购前口径）：EDA 软件授权与工程服务为主，营收 4.84 亿，**毛利率约 85%**（2026H1 为 85.12%，Tushare fina_indicator，高）——纯软件商业模式的毛利率水准与华大九天（87.5%）同档。并购并表后，低毛利的 IP 授权/芯片定制业务将拉低综合毛利率（锐成芯微以授权+定制为主，毛利结构低于纯 EDA，估算口径）。

### 2.4 技术代际演进与技术发展方向

- **当前代际**：器件建模环节（从测试数据到 SPICE 模型提取、验证、PDK 交付）处于**全球第一梯队**——这是先进制程开发的"编译器"：每一代新工艺（3nm/2nm、GAA、SiC/GaN）都需要新的器件模型，模型不准则整个设计生态的仿真全部失真。**先进制程越演进，对建模精度与自动化要求越高，该环节不可绕过**（行业分析，中高；"不可替代"表述属投资者观点而非官方论断，本文降格为"高粘性、难绕过"）。
- **演进路径**：手工建模 → 自动化提取（SDEP）→ 建模-仿真-验证一体化（BSIMProPlus+NanoSpice）→ DTCO（设计-工艺协同优化）。
- **未来布局**：①EDA+IP 协同（对齐 Synopsys"工具+IP"飞轮）；②先进封装/Chiplet 时代的多裸片协同建模（行业方向，中）；③AI 辅助建模（Synopsys Sentaurus 2026.03 已引入 AI 驱动 TCAD 工作流，竞品压力，中高）。

> **核心洞察**：器件建模是 EDA 产业链中一个"小而险要"的关隘——市场空间远小于数字全流程，但它卡在晶圆厂与设计公司之间的 PDK 咽喉上，且每一代制程迭代都要重做一遍。概伦在这口井里挖到了全球头部客户，代价是井口太窄（中国市场空间受限）；21.74 亿并购本质是**用井的深度去换河的宽度**。

### 3.2 拐点成因诊断

1. **2025 扭亏是"非经撑起的中转站"**：归母 +0.34 亿 vs 扣非 -0.60 亿，差额近 1 亿来自非经常项；预告 +137.5% 为**低基数效应**（2024 亏 0.96 亿），引擎 FC 因子分 100 分需人工校正（forecast.py，20260830）。
2. **2026H1 再转亏**：营收 +10.0% 尚可，但研发费用 1.34 亿（半年）已超毛利贡献——单靠 2.4 亿收入无法覆盖 55.94% 研发强度下的费用刚性；叠加并购交易费用与季节性（EDA 收入 Q4 集中），上半年亏损结构性重现（Tushare/行业惯例推断，中高）。
3. **行业性"增收不增利"**：华大九天 2026H1 转亏 -0.45 亿、广立微扣非 -25.3%——国产 EDA 三家全线处于"用利润换时间"阶段（各家年报，高；产业链研报 §5.4）。

### 3.3 资产负债表质量

2025FY 经营现金流 +1.38 亿（远超归母净利 0.34 亿，净现比 ~4x），授权业务预收特性下现金创造能力优于利润表（Tushare，高）。2026H1 经营现金流 -0.51 亿（季节性+并购扰动）。**并购交割后新增两大变量**：①锐成芯微 100% 股权评估增值率 150.06%、纳能微 45.64% 股权增值率 346.34%（财联社，高）——对应约十余亿商誉挂账（估算）；②发股+配套募资使净资产增厚、摊薄每股指标。公司自身已在公告中提示"未来持续并购可能形成新的商誉风险"（公告，高）。

### 3.4 现金流质量

2025 净现比 ~4x 验证收入真实性；2026H1 转负属季节性（EDA 授权 Q4 确认 + 并购一次性费用）。**并购后备考现金流的观察重点从"EDA 授权预收"切换为"IP 授权的 royalty 现金流质量"**（估算口径，需年报验证）。

> **核心洞察**：概伦的利润表是国产 EDA 三家中最" illusion 密集"的——2025 扭亏靠非经、2026H1 转亏靠实质、预告 +137.5% 靠基数。穿透后的事实只有一个：**主业盈亏平衡点对应约 5.5-6 亿营收（研发 2.7 亿/年 + 其他费用估算），当前 4.8 亿的本部收入仍在平衡点之下**，并购并表收入能否把公司整体推过平衡点，是未来四个季度唯一重要的财务问题。

## 第四章：景气度分析——G+ΔG 框架下的定位

### 4.2 G 与 ΔG 人工核算

- G（营收增速）：2025FY +15.41% → 2026H1 +10.0%。**ΔG ≈ -5.4pct（半年维度），与引擎 -2.68pct 方向一致：营收在减速**。
- 利润维度 G 为负（再转亏），利润分 0。

### 4.3 山峰理论定位

Δg 符号为负 + 增速从 15% 向 10% 滑落 → **左山坡的回落段或小山头右侧**——2025 年的"扭亏+15% 增速"构成一座小山，2026H1 数据显示正在下山。但并购并表将使 2026H2-2027 的营收基数发生跳变，**山峰形状本身即将被并购重塑**，当前拐点信号的技术意义有限。

### 4.4 30% 阈值检验

营收增速 10-15% < 30% 阈值——不满足高景气筛选标准。与华大九天相同，处于"战略高景气（国产替代+先进制程建模刚需）、财务低景气"的错位带。

### 4.5 二次点火筛选

未触发。观察点：并购并表后首个完整年度（2026FY/2027Q1）备考营收增速若跳升至 30%+ 且扣非亏损收窄，构成二次点火候选。

> **核心洞察**：引擎给的"下降拐点"是本部口径的真实信号，但它即将被一次会计意义上的"并购换挡"覆盖——**分析概伦的景气度，本部报表看方向、备考报表看弹性，两者都不能单独下结论**。
