### 1.3 公司定位与业务布局

**一句话定位**:DSA(Domain-Specific Architecture,专用架构)路线的国产 AI 芯片设计公司——"邃思"系列芯片 IP + 云燧 i(推理)/T(训练)产品线 + 驭算(TopsRider)全栈软件 + 智算集群方案,深度绑定腾讯生态。

**关键路线标签**:**不兼容 CUDA、自建生态**——与摩尔线程/沐曦(GPGPU、CUDA 迁移友好)分道,与华为昇腾同属 DSA 阵营。灼识咨询:2025 年国内 DSA 架构市占 57%(华为海思/寒武纪/燧原/昆仑芯等),GPGPU 占 43%(新京报引招股书)。
