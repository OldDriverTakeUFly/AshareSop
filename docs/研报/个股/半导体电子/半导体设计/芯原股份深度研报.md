## 第一章:公司概览与股东背景

### 1.1 创始人与管理层

**戴伟民博士(Wayte Dai)——创始人、董事长兼总裁**

戴伟民是芯原股份的**创始人、董事长兼总裁**,半导体 IP 行业的资深人士。他出身学术和技术背景,长期深耕芯片 IP 和 ASIC 定制服务领域。

**创业路径**:

- 芯原微电子(上海)股份有限公司于 **2002 年**创立(戴伟民回国创业),从芯片设计服务起家。
- 公司逐步从单纯的 ASIC 定制服务,扩展至**自主半导体 IP 授权**业务,形成"IP + 定制"双轮驱动。
- **2020 年 8 月 18 日**,芯原股份登陆科创板(688521.SH),成为科创板首批半导体 IP 上市公司之一。
- 2024-2026 年,戴伟民主导公司战略转型:从"中国 IP 企业"走向"全球 ASIC 龙头",受益 AI 定制芯片浪潮。

**管理风格**:戴伟民是典型的**技术驱动型 + 国际化视野**企业家,频繁在国际半导体行业大会发表主题演讲(如以"Chiplet 在智慧出行领域的产业化之路"为题)。他强调芯原的定位是"逆全球化背景下,从中国 IP 企业走向全球 ASIC 龙头"(财联社 2026-05)。

**管理层特点表格**

| 维度 | 描述 |

| 创业路径 | 2002 年创立 → 2020 年科创板上市 → 2024-2026 年 AI ASIC 浪潮受益 |
| 管理风格 | 技术驱动 + 国际化视野,行业大会活跃 |

## 第二章:业务范围与产品矩阵

### 2.1 经营范围(法定)

芯原股份的主营业务为 **半导体 IP 授权 + 芯片定制一站式服务(ASIC)**,覆盖芯片设计全流程(架构设计 → IP 集成 → 流片 → 量产)。

### 2.2 核心产品矩阵——IP + 定制双轮

| 业务板块 | 核心产品 | 应用场景 | 行业地位 |
|----------|---------|----------|----------|
| **半导体 IP 授权** | GPU IP、NPU IP、VPU IP(Hantro)、DSP IP、ISP IP + 1400+ 数模混合 IP | 云 AI、端侧 AI、汽车、物联网 | 中国第一、全球前十 |
| **芯片定制(ASIC)** | 一站式设计服务(架构 → 流片) | 云厂商自研 AI 芯片、汽车芯片 | 中国 ASIC 龙头 |
| **Chiplet(第二曲线)** | Chiplet 互联 + 封装方案 | 大型 AI 芯片、汽车芯片 | 产业化推进中 |

### 2.3 分业务收入结构(2025 估算)

### 2.4 技术代际演进与技术发展方向(强制!)

**当前技术代际位置**:芯原处于 **AI ASIC 定制 + Chiplet 产业化早期**,五大数字处理器 IP 已成熟,Chiplet 是下一代增长曲线。

**IP 代际演进路径**:

```
传统 IP(CPU/GPU 基础)→ AI IP(NPU/VPU,受益 AI 浪潮)
→ Chiplet IP(互联 + 封装,下一代大型芯片)
```

**关键技术优势**:

| IP 类别 | 芯原地位 | 应用 |
|---------|---------|------|
| GPU IP | 全球前三(与 ARM/Imagination 竞争) | 云 GPU、端侧图形 |
| NPU IP | 全球领先 | AI 推理/训练 |
| VPU IP(Hantro) | **全球前 20 云平台 12 家采用** | 视频编解码 |
| DSP IP | 全球前三 | 通信、音频 |
| ISP IP | 全球领先 | 图像信号处理 |

**Chiplet 第二曲线**:

- 戴伟民主导 Chiplet 产业化,智慧出行(汽车芯片)、AI 大芯片是主战场。
- 大型 AI 芯片(如英伟达 B200、AMD MI300)已采用 Chiplet 架构,芯原的 Chiplet IP + 定制服务有切入机会。
- 中国造车新势力 Top 8 中 5 家进入芯原供应链(财联社 2026-05)。

> **核心洞察**:芯原的 IP 矩阵是"AI 时代的瑞士军刀"——云厂商自研 AI 芯片需要 GPU/NPU/VPU 全套 IP,芯原是少数能一站式提供的厂商(ARM 只做 CPU IP,Imagination 只做 GPU IP)。这种**全平台 IP 储备**在 AI ASIC 浪潮中是稀缺资产。Chiplet 是第二增长曲线,但产业化仍处早期,需 2-3 年验证。

### 2.5 海外/新兴业务

芯原是**国际化程度最高的国产半导体 IP 公司**,美国、欧洲设有研发中心,海外客户占比高。这是与纯国内 IP 厂商的核心差异。

### 3.2 亏损持续的成因诊断

芯原长期亏损由以下因素驱动:

2. **毛利率下行**:ASIC 定制业务毛利(30-35%)低于 IP 授权毛利(70-90%),业务结构变化拉低整体毛利。
3. **规模效应不足**:芯原营收 31.52 亿元,远小于 ARM(约 30 亿美元),规模效应不足以覆盖研发。

## 第九章:风险提示与研究局限

### 9.1 主要风险(≥4 条,编号)

1. **盈利兑现延迟风险**:芯原自 2023 年持续亏损,2026Q1 仍亏 3.41 亿元。若 AI ASIC 规模化未能覆盖高研发投入(2025 研发 13.13 亿),亏损可能持续超预期。

2. **毛利率持续下行风险**:毛利率从 2022 的 41.6% 降至 2026Q1 的 32.3%,反映 ASIC 定制业务(低毛利)占比提升。若毛利率跌破 30%,盈利难度进一步加大。

3. **Chiplet 产业化延迟风险**:Chiplet 是第二增长曲线,但产业化仍处早期。若大型 AI 芯片厂商(英伟达/AMD)自研 Chiplet 不外包,芯原的 Chiplet 业务可能不及预期。

4. **估值回调风险**:当前 PB 95.8% 分位、PS 89.8% 分位,**估值处历史高位**。若 AI 概念降温或业绩低于预期,可能剧烈杀估值。

5. **规模劣势风险**:芯原营收仅 ARM 的 1/10,规模效应不足以覆盖研发。若 IP 行业整合加速(Synopsys/Cadence 并购),芯原可能被边缘化。

6. **筹码分散风险**:2025Q3 户数翻倍(+94.5%),筹码剧烈分散,动能减弱,股价回调风险增加。

7. **地缘政治风险**:芯原国际化程度高(美国/欧洲研发中心),可能受中美科技摩擦影响。

### 9.2 研究局限(诚实声明)

- **估值方法局限**:芯原亏损,PE 失效,PS/DCF 假设含不确定性(2026E 营收 45-70 亿,2027-2028 年盈利)。
- **2026 半年报未披露**:营收加速的持续性需半年报验证。
- **分业务收入结构为估算**:详细分业务需 2025 年报披露。
- **筹码集中度数据不全**:仅 2 期户数数据,趋势判断有限。
- **未编造任何数据**:所有标注"估算/NA/待披露"的项均为信息缺口,本报告如实呈现。
