## 发布操作(手动,勿自动化)

1. 雪球 App/网页 → 写长文;正文从 md 粘贴后核对表格与加粗是否保留(表格丢失则截图研报表格替换);
2. cashtag 粘贴后确认变蓝成链接($牧原股份(SZ002714)$ 格式),变蓝才会挂到个股页讨论流——这是雪球的核心长尾流量;
3. 话题标签建议:#产业链分析 #周期股 #(对应行业);
4. 发布时间不限(雪球无强黄金档,工作日早间或晚间均可);三篇间隔 ≥1 天;
5. 发布后回填:在本 README 表格加"已发布+链接"列。

## 合规红线(雪球执行比小红书严、边界更清晰)

- 不收费、不拉群、不给具体买卖点位/目标价——现有文案已按敏感词闸自检;
- 每篇头尾均有"不构成投资建议"免责,发布前勿删;
- 评论区不荐股、不报仓位,可讨论数据与逻辑。

## 转换口径(脚本已处理,复用时参照)

- 锚点目录删除(雪球不支持页内跳转);内部文件路径/仓库名外部化;

- 公司名首现替换为 cashtag,其余保持原文;数字零改动。
